# 智能列表共享契约 v1

适用阶段：桌面 DNS2、鸿蒙 HNS2。两仓库保存相同副本及 `docs/fixtures/smart-views-v1.json`，不修改 Todo、S3 Object Key 或同步 schema。

## 筛选规则

统一先排除 deleted / archived 任务。以设备当前本地时区为准，用本地日历构造日期边界，不用 24 小时毫秒数代替一天。

| ID | 范围 |
| --- | --- |
| `overdue` | 未完成，截止日期/时刻严格早于本地今天 00:00 |
| `next7` | 未完成，从今天 00:00 到第 7 天 00:00，左闭右开，即今天及后 6 天 |
| `no_date` | 未完成，没有 due_date 且没有 due_at；提醒时间不算截止日期 |
| `important` | 未完成，priority 为 1 |
| `recently_completed` | 已完成，completed_at 从第 -6 天 00:00 到当前时刻，含两端；不含未来时间和空时间 |

- 今天早些时候到期的未完成任务仍属于未来 7 天，不属于智能“逾期”。原有“今天”视图继续显示今天及更早到期的未完成任务，两者并不互斥。
- `due_date` 按本地日期读取，不能按 UTC 字符串日期解析。现有同步协议不允许同时有 due_date 与 due_at；防御性筛选遇到两者时按日期字段处理。
- 鸿蒙现有 DTO 用本地午夜 dueAt 接收纯日期；测试同时覆盖规范字段和实际 DTO 适配。无效日期不纳入日期列表。
- 在不同时区，同一绝对时刻可能分属不同本地日期，这是预期差异。要求相同本地时区及相同数据时两端一致，不改变原有跨时区存储协议。

## 组合与交互

- 分组和搜索与智能列表取交集；搜索标题和备注，忽略大小写及首尾空白。
- 未完成类列表不显示已完成任务；最近完成不受“隐藏已完成”影响。
- 四象限、日历作为展示方式继续叠加筛选。菜单计数只应用分组、搜索和智能规则，不再叠加选中的日期或象限。
- 选择列表进入“全部”的列表布局；点击“全部”“今天”或进入便签清除智能筛选。点击筛选胶囊的关闭只清除智能条件，保留当前展示方式。
- 两端恢复保存的有效智能选择时，进入全部列表布局。无效值按未选择处理。
- 保留原任务顺序，不回写 sort_order。在智能子集禁用排序；正常分组移动、编辑及完成操作仍可使用。
- 本机选择不进入 S3 同步文档，鸿蒙使用现有 metadata 记录，不需要新数据库 migration。它不是跨设备偏好同步。
- 在前台按分钟刷新筛选时刻，秒级检查分钟/时区变化；午夜最多约 1 秒刷新。任务数据变化、重新显示页面及回到前台时刷新，避免每秒重建大列表。后台不承诺保持 UI 定时器运行。

## 两端入口

- 桌面：更多菜单内五项智能列表及计数；菜单按剩余视口高度滚动，英文名称按词换行；当前筛选显示关闭胶囊。
- 手机：更多 → 智能列表 → 选择项，选择层可滚动。
- 平板：左侧智能列表可折叠区域，不增加顶部常驻按钮。
- 文案使用现有中英文机制；鸿蒙使用主题资源、圆角控件、文本及关闭按钮无障碍描述。

## 自动验证

桌面仓库运行：

```powershell
pnpm views:check
node scripts/check-smart-views.mjs --harmony=../EggDoneHarmony
pnpm release:check
```

`views:check` 已接入桌面发布检查。跨端命令检查 fixture 副本一致，转译并执行两个实际纯函数，再验证鸿蒙 Todo DTO 适配，并非只比较两个复制的测试算法。

- 31 个定义案例：上海 30、UTC 29、纽约 30，共 89 个时区案例。
- 覆盖未设置日期、纯日期、绝对时刻、今天早些时候、午夜、7 天两端、最近完成窗口、未来完成时间、删除、归档、闰日、年末、夏令时进入和退出。
- Vitest 覆盖分组、备注搜索、隐藏已完成、四象限/日历筛选组合和顺序不变。
- Harmony Local Test 覆盖有效选择、日期边界、已完成条件和 500 条记录不变性。
- 500 条纯函数测试不代表设备 UI 性能验收；浏览器注入模拟 IPC 数据不代表真实 Tauri 数据库或鸿蒙 RDB 验收。

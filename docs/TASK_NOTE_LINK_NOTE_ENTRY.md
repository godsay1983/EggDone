# 便签创建关联任务（L4b）

更新：2026-09-12。未升版、未发布。L4a已提交：桌面9e3bbd2、鸿蒙e42ff54。

## 操作入口

1. 打开一张已保存的便签，点击编辑器的“添加 → 创建关联任务”。
2. 标题默认取便签标题，可修改；任务备注为空，不复制便签正文或附件。
3. 可设置全天日期和独立提醒。没有日期仍是无日期任务；没有提醒不注册提醒。
4. 确认后留在原便签，展开“关联任务（数量）”查看标题及未完成、已完成、已归档、已删除或暂不可用状态。
5. 取消只关闭任务草稿，不创建任务或关联。原便签沿用自动保存规则；打开创建面板前会先完成便签待保存内容。

未保存便签暂不开放入口；先保存便签再操作。便签没有关联且读取成功时不显示空列表。列表读取失败有重试，不把失败当作“没有关联”。

## 实现边界

- 桌面由TaskNoteLinkStore编排来源保存、原子命令和刷新；鸿蒙由同名Store调用既有TaskNoteLinkService和原子操作。
- 每次打开面板生成稳定任务UUID，重复点击被阻止；写入失败保留草稿，重试沿用UUID。已提交但刷新失败提示刷新异常，不再把它当作创建失败。
- 任务与关联同事务写入，沿用L2回执与L3同步dirty语义；桌面更新列表与托盘，鸿蒙接入既有列表、卡片和提醒刷新。文本已保存不代表云端同步成功。
- 来源便签切换受到保护；关联列表按便签UUID隔离，过时异步读取不能覆盖新便签。
- 两端使用现有操作按钮样式。桌面原生日期输入、滚动字段区和固定操作区；鸿蒙复用IntentCaptureDialog的日期/提醒选择器，仅新增标题和提示显隐参数，不改小艺协议或执行器。
- 重复任务仍仅关联当前实例，不传播到下一实例。删除、缺失状态不显示已删除内容标题。
- 本阶段列表只读；从任务打开便签、关联已有内容、解绑与往返上下文属于L4c。L4整体和发布验收没有完成。

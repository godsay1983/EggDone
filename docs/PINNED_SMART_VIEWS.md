# 常用筛选固定入口（E6c）

更新：2026-09-12。双端实现完成，用户验收待确认；按用户要求本地提交，不推送、升版或发布。

## 行为与边界

- 复用五种已有智能列表：逾期、未来 7 天、无日期、重要、最近完成；不新增规则引擎或主导航页面。
- 默认没有固定项；最多两个，按固定先后顺序排列。取消后再固定排到末尾，不暗中替换另一个固定项。
- 固定仅创建快捷入口，不立即改变当前筛选。取消固定也不清除当前筛选；清除当前筛选不删除固定入口。
- 点击快捷入口沿用已有 selectSmartView 路径，分组和搜索仍与智能列表取交集，任务/便签导航及草稿保存保护不变。
- 入口只在任务区域显示；没有固定项时不占位。手机、平板和桌面均使用可换行的独立快捷区域，不把所有智能列表塞进主导航。
- 仅保存本设备偏好，不进入任务同步、导入导出或云端；两端可固定不同列表。

## 界面

桌面：更多菜单中，每个智能列表旁有星形固定开关（带操作名称、选中状态及提示）；标题显示固定数量。主任务区显示最多两个常用入口，当前选中高亮。窄窗口导航允许换行，确保更多入口不被挤出。

鸿蒙：手机“更多 → 智能列表”、平板侧栏“智能列表”都使用同一 SmartViewPicker，每行有“固定/取消固定”。选中高亮仅表示当前筛选，不表示是否固定。固定入口使用既有 ActionButton，文字随系统字号，不根据屏幕宽度放大；Flex 折行，不新增断点、窗口监听、侧栏或路由。

## 存储契约

```json
{"version":1,"ids":["no_date","next7"]}
```

- 桌面：现有原生 general_preferences_v1 中的 eggdone-pinned-smart-views 单项；浏览器测试回退 WebView 存储。
- 鸿蒙：现有 app_metadata 中独立 pinned_smart_views_v1 键。沿用参数绑定，无新表及数据库 schema 迁移。
- 与当前 smart_view/eggdone-smart-view、默认视图、分组和搜索独立。
- 无记录返回空列表；未知版本、损坏 JSON、未知 ID、重复 ID、超出两项均拒绝，不静默覆盖。
- 持久化成功后才更新确认状态；保存失败显示原固定项并提供重试。加载失败不开放编辑；忙碌时禁止重复点击。
- 写前再读并验证现值；桌面原生已有单项合并保留其他偏好，多窗口同时修改同一固定列表仍为最后写入者优先，不提供跨窗口集合事务合并。
- 升级无需重新选择现有筛选。桌面旧程序对原生偏好键有严格白名单；不要承诺写入新键后直接回退旧二进制仍兼容所有偏好，降级需要单独方案。

## 人工验收步骤

1. 打开智能列表，固定“未来 7 天”和“无日期”，确认主任务区出现两个入口；第三项不能再固定。
2. 点击“无日期”，确认任务内容筛选正确。回到智能列表取消其固定，确认快捷入口消失，但当前仍筛选无日期任务。
3. 取消另一项，再固定“重要”；退出并重新启动应用，检查入口及顺序保留，分组和其他设置未被改写。
4. 切到便签再返回，确认已有返回和草稿保护正常，固定列表不变。
5. 检查手机、平板及窄分屏、大字体；桌面窄窗口和 125% 缩放、中英文下 More/更多与固定开关均可操作。

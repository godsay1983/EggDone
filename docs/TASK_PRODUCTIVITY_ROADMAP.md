# 双端任务效率功能 Roadmap

日期：2026-09-14。
本轮只包含用户选定的三项：任务内检查清单、任务模板与快捷复制、多行文本批量创建。
不恢复旧长期目标，不包含专注统计、自动备份、小艺或实况窗修改。
方案：[TASK_PRODUCTIVITY_IMPLEMENTATION_PLAN.md](TASK_PRODUCTIVITY_IMPLEMENTATION_PLAN.md)。
共享规则：[TASK_PRODUCTIVITY_CONTRACT.md](TASK_PRODUCTIVITY_CONTRACT.md)。

## P0：方案与草稿基础

- [x] 核对两端当前版本、架构与已有创建/同步能力。
- [x] 明确三项范围、限额、复制重置、模板快照和批量预览规则。
- [x] 实现两端一致的纯草稿内核与共享样例；18 组契约测试分别通过，文档/样例/代码双端一致。
- [x] 运行草稿测试、双端一致性检查、桌面类型检查及鸿蒙静态检查/构建。

P0 不产生产品入口、不修改用户数据或数据库。界面没有变化是预期，不需要现在安装验收。

## P1：任务内检查清单（第一个可用功能）

- [x] P1a 冻结实例子项、系列定义、冲突全序、确定性生成、独立同步对象和备份新版本的共享 fixtures；[协议与参考实现边界](TASK_CHECKLIST_PROTOCOL.md)。仅参考契约完成，不代表生产解析器/持久化/网络完成。
- [x] P1b 双端增量迁移、独立 repository、父任务保存与清单原子事务、删除/恢复、旧库及失败回滚测试。内部存储能力完成；产品接线、原生设备和系统提醒验收仍属 P1d/P1e。
- [x] P1b-1 存储基础：双端生产协议、迁移、独立 repository、标题/备注与本次清单原子保存、删除恢复、旧库/回滚/重开测试；[实现记录](TASK_CHECKLIST_STORAGE.md)。
- [x] P1b-2 完整任务编辑事务，以及“以后”清单的规则分叉+定义+当前清单原子保存；[实现记录与接入边界](TASK_CHECKLIST_EDITOR.md)。
- [x] P1c 双端真实业务同步、重复实例继承和补齐、备份导入导出；隔离环境验证并发/离线/错误/重试。设备及实际 S3 验收仍在 P1e。
- [x] P1c-1 双端生产重复实例继承与迟到补齐，接入生成事务和同步前本地准备；[实现与验证边界](TASK_CHECKLIST_INHERITANCE.md)。

- [x] P1c-3 备份 v4 的完整导入导出、预览和恢复原子性，覆盖旧格式保留与跨端兼容；[实现和验证边界](TASK_CHECKLIST_BACKUP.md)。
- [x] P1d 双端详情/编辑清单、任务行计数、取消不落库、保存失败保留草稿已实现；用户已确认基础操作通过。手机/平板完整尺寸、键盘与语言矩阵的未测项保留在 P1e/P4，不以此项表示全矩阵验收通过。

不能仅有勾选界面就勾选整个 P1。

## P2：模板与快捷复制（第二个可用功能）

- [x] P2a 复制任务生成新草稿、不继承旧提醒/日期/规则/关联；复用原子创建及失败重试，两端产品入口已接入。自动化与原生验收分开记录，见[实现与验收](TASK_QUICK_COPY.md)。
- [x] P2a-验收 用户反馈快捷复制“测试通过，提交”；具体设备、运行包和真实同步环境未逐项展开，不等同于 P2d 完整矩阵验收。
- [x] P2b 内部模板保存/修改/删除、独立同步与备份，模板快照不依赖原任务存在；产品入口在 P2c，设备验收在 P2d。
- [x] P2b-1 独立模板协议、共享冲突样例、双端增量迁移和 repository 增删改/乐观快照/回执事务；[实现与验证边界](TASK_TEMPLATE_STORAGE.md)。内部存储完成，尚无产品入口。
- [x] P2b-2 模板独立网络对象、配置世代与 revision/ACK、错误重试、备份 v5 及跨端交换回归；[实现与验证](TASK_TEMPLATE_SYNC_BACKUP.md)。隔离测试通过，不等于设备和实际 S3 验收。
- [x] P2c 任务保存为模板、模板管理/选择/搜索/预览与创建；空列表、失效分组、冲突和失败重试已接入，构建与隔离回归通过。见[入口与验收边界](TASK_TEMPLATE_UI.md)；设备验收仍属 P2d。
- [ ] P2d 双端回归与手机/平板/桌面人工验收，更新说明。

交付标准：一份模板可以多次生成互不影响的任务及清单，旧提醒不会被重新注册。

## P3：多行文本批量创建（第三个可用功能）

- [x] P3a 双端批量写入接口、整批事务与本机操作回执，失败零新增、相同请求重试不重复；旧回执核对当前任务状态。隔离验证通过，尚无界面入口，见[事务层与接线要求](TASK_BATCH_CREATION.md)。
- [x] P3b 主动粘贴、行号/重复提示、修改与勾选、统一分组、数量与确认；双端入口及原子提交已接入，隔离会话/面板/浏览器验证通过，见[界面与验证边界](TASK_BATCH_UI.md)。跨进程恢复见 P3c-1，真机验收仍待 P3c-2/P3d。
- [ ] P3c 创建结果刷新、同步与错误恢复；中文英文、大字号、软键盘、长预览测试（代码和隔离验证完成，设备验收未完成）。
- [x] P3c-1 本机未确认请求持久化、重启原样恢复、明确清理失败状态与二次确认结束恢复；完整负载比较和刷新隔离回归通过，见[恢复与验证边界](TASK_BATCH_RECOVERY.md)。
- [ ] P3c-2 手机/平板软键盘、大字号、分屏、真实批次同步及原生重启恢复验收。
- [ ] P3d 双端验收与文档收口。

交付标准：有效选中项一次创建；取消不创建；任何一项写入失败整批回滚，重试无重复。
首版不自动解析批量标题中的时间，不把 Markdown 已勾选标记变成已完成任务。

日期：2026-09-14。
本轮只包含用户选定的三项：任务内检查清单、任务模板与快捷复制、多行文本批量创建。
不恢复旧长期目标，不包含专注统计、自动备份、小艺或实况窗修改。
方案：[TASK_PRODUCTIVITY_IMPLEMENTATION_PLAN.md](TASK_PRODUCTIVITY_IMPLEMENTATION_PLAN.md)。
共享规则：[TASK_PRODUCTIVITY_CONTRACT.md](TASK_PRODUCTIVITY_CONTRACT.md)。

## P0：方案与草稿基础

- [x] 核对两端当前版本、架构与已有创建/同步能力。
- [x] 明确三项范围、限额、复制重置、模板快照和批量预览规则。
- [x] 实现两端一致的纯草稿内核与共享样例；18 组契约测试分别通过，文档/样例/代码双端一致。
- [x] 运行草稿测试、双端一致性检查、桌面类型检查及鸿蒙静态检查/构建。

P0 不产生产品入口、不修改用户数据或数据库。界面没有变化是预期，不需要现在安装验收。

## P1：任务内检查清单（第一个可用功能）

- [ ] P1a 冻结实例子项、系列定义、冲突全序、确定性生成、独立同步对象和备份新版本的共享 fixtures。
- [ ] P1b 双端增量迁移、独立 repository、父任务保存与清单原子事务、删除/恢复、旧库及失败回滚测试。
- [ ] P1c 双端真实业务同步、重复实例继承和补齐、备份导入导出；隔离环境验证并发/离线/错误/重试。
- [ ] P1d 双端详情/编辑清单、任务行计数、取消不落库、保存失败保留草稿；手机/平板响应式与中英文。
- [ ] P1e 完整回归，提供配套测试包与可操作验收清单，记录人工结果。

交付标准：用户可新增、编辑、勾选、删除子项；两端同步一致；主任务完成、归档、删除恢复和重复实例符合契约。
不能仅有勾选界面就勾选整个 P1。

## P2：模板与快捷复制（第二个可用功能）

- [ ] P2a 复制任务生成新草稿、不继承旧提醒/日期/规则/关联；原子创建及失败重试。
- [ ] P2b 模板保存/修改/删除、独立同步与备份，模板快照不依赖原任务存在。
- [ ] P2c 新增菜单的模板选择、搜索、预览与创建；无模板和失效分组状态。
- [ ] P2d 双端回归与手机/平板/桌面人工验收，更新说明。

交付标准：一份模板可以多次生成互不影响的任务及清单，旧提醒不会被重新注册。

## P3：多行文本批量创建（第三个可用功能）

- [ ] P3a 后端统一批量命令，整批事务与稳定操作回执，失败零新增、超时重试不重复。
- [ ] P3b 主动粘贴、行号/重复提示、修改与勾选、统一分组、数量与确认。
- [ ] P3c 创建结果刷新、同步与错误恢复；中文英文、大字号、软键盘、长预览测试。
- [ ] P3d 双端验收与文档收口。

交付标准：有效选中项一次创建；取消不创建；任何一项写入失败整批回滚，重试无重复。
首版不自动解析批量标题中的时间，不把 Markdown 已勾选标记变成已完成任务。

## P4：配套发布

- [ ] 两端完整自动化、旧库升级、旧端混用、提醒与备份恢复回归。
- [ ] 手机/平板/桌面用户验收，未测范围明确记录。
- [ ] 用户授权后提升版本、更新 changelog/handoff、提交和构建安装包。
- [ ] 用户另行授权后推送、合并或发布。

每个功能完成后给出操作步骤和证据；不预先勾选人工验收。
2026-09-14 用户授权先提交 P0，再开始 P1a；不推送、升版或发布，开发保留在两端 codex/task-productivity 分支。

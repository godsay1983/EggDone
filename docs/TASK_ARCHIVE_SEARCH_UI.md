# 归档搜索与列表层次

日期：2026-09-17。阶段：LC1b-2b，代码和自动化完成，纳入本地提交、未发布。原生/真实同步验收属于 LC1c。

## 用户可见变化

- 归档和回收站每条记录增加低对比底色、细边框、6px/vp 行间距及 6px/vp 圆角，保留紧凑字号。桌面悬停/键盘焦点加强边界；批量选中使用淡黄色底与强调边框，鸿蒙保留左侧原生复选框。
- 统一搜索增加“包含已归档任务”，默认开启，仅影响任务结果。过滤在数据库计数/分页之前进行，便签与附件结果不受影响。
- 搜索中的归档任务打开同一归档详情及确认流程，可取消归档、重新打开或移入回收站；取消不写入。返回保留关键词、分类、包含归档选项、分页与滚动，并刷新当前结果；删除造成末页为空时退到最后有效页。
- “清除已完成”改为“删除已完成”，确认明确进入回收站且可以恢复。桌面仍是原有二次点击确认，鸿蒙仍是确认面板，不改变实际删除逻辑。
- 列表补充分组；详情提示原任务日期已过，提醒用户重新打开不会自动恢复旧提醒。不把已完成的归档任务标成当前待办逾期。
- 详情提供有效关联便签入口，首版为当前标题和正文的只读文字预览。打开前重新检查归档任务、关联和便签可用性；失败提示并允许重试，不以失败冒充没有关联。
- 便签预览内仅提供返回归档详情，不混入任务恢复操作。附件预览、便签编辑和关联修改仍走原入口，本阶段不自动下载文件。

## 实现边界

- 桌面样式集中于 management-dialog.css，鸿蒙集中于 ManagementListRow；不改全局按钮、主任务行或便签卡片。
- 搜索开关保存在当前搜索会话，不增加持久偏好或 schema。旧 IPC 调用未传过滤字段时默认包含归档。
- 复用 ArchiveStore / 原有归档命令和版本确认，不另建恢复写入路径，不更改重复规则、提醒保护、固定目标及操作回执。
- 搜索返回刷新有代次隔离，旧查询或旧分页的迟到响应不会覆盖当前结果。
- 应用版本、数据库 schema、同步 wire、Object Key、备份 v5、小艺配置不变；没有开放彻底删除/清空回收站。
- 没有安装覆盖设备应用，没有修改用户任务或同步存储。

## LC1c 验收

本轮桌面截图目录（隔离测试数据）：归档 eggdone-archive-ui-1789638134208、统一搜索 eggdone-content-search-ui-1789638064482、回收站 eggdone-trash-ui-1789638244331，位于 Windows 用户临时目录。截图不入库。

1. 桌面、手机和平板打开归档/回收站：检查每条任务的底色和边界，选中与未选中可区分；暗/亮主题、窄窗和大字体不截断。
2. 统一搜索查找归档任务，关闭/打开包含归档，观察任务数量与分页变化；便签和附件数量不应变化。
3. 从搜索打开归档任务，分别取消操作、取消归档、重新打开、移入回收站；返回检查关键词、分类和当前位置，以及最新状态。
4. 归档详情检查分组、过去日期、清单和关联便签文字；进入便签预览后返回，不能误执行任务恢复。
5. 已完成任务删除确认明确回收站去向，删除后可在回收站找到并恢复。
6. 真实隔离同步验证：一端归档另一端取消归档/重新打开；不重新提醒、不推进旧重复记录。离线/冲突与手机平板原生布局仍需实际验收。

## 操作步骤

1. 两端任务选择今天或智能筛选，输入搜索词，再进入便签。桌面便签应使用自己的搜索词；返回原任务页，原筛选及搜索应仍在。鸿蒙使用“返回任务”。
2. 便签列表足够长时滚动到中部，打开便签、编辑并完成；返回列表应停留在原位置附近。对任务列表进入便签再返回重复检查。
3. 鸿蒙平板编辑便签，进入设置或分组后按系统返回，编辑器和内容应保留；手机从便签更多进入同样检查。
4. 保存失败时尝试离开，应留在原编辑页，修复原因并重试后才能离开；此项可保留专项故障验证，勿破坏真实数据。
5. 鸿蒙横竖屏、分屏切换时检查列表/编辑栏切换，滚动恢复不应把正在编辑的正文关闭。

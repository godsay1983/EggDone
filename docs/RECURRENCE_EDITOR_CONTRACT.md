# 自定义重复规则编辑事务契约

日期：2026-09-06
阶段：DNS5-E3A / HNS5-E3A
状态：内部创建、替换与停止事务完成；读取沿用规则快照。规则备份恢复已实现，见 [备份契约](RECURRENCE_BACKUP_CONTRACT.md)；尚未开放 UI，原生设备与真实 S3 验收仍需完成。

## 接口与职责

- 桌面：recurrence_editor::save_rule / stop_rule；调用方持有数据库锁，模块拥有独立 IMMEDIATE 事务。
- 鸿蒙：RecurrenceEditorRepository.save / stop；与完成、删除、规则合并共用 RecurrenceQueue，使用原生独立 Transaction，不嵌套旧 RdbStore 事务。
- 读取使用已有规则 snapshot；它提供完整规则，供后续编辑器保存时进行乐观并发核对。
- 编辑请求 RuleEditRequest 包含 rule（新规则完整初始记录）、expected_todo_updated_at 和 replaces（旧规则完整快照或 null）。
- 新规则 UUID 由调用方一次生成，失败重试保留整个请求；同 UUID 不能用于不同编辑。
- 调用方后续应使用本机 DeviceRepository/device_id 提供 updated_by；此保存操作会写 Todo，要求标准带连字符 UUID，不能只满足规则协议的 ASCII 设备标识校验。

## 创建规则

1. rule 必须通过 v1 严格校验，generated_count=1、exhausted=false、deleted_at=null；当前 UUID 等于首任务 UUID，日期等于有效的计划首日。
2. 当前任务必须在本机存在、未完成、未删除、未归档，updated_at 与编辑时读取值相等。
3. 本步仅允许从未关联重复系列的普通任务创建；原快捷 repeat_rule、未知系列、已停止系列和历史项不能静默转换。
4. 规则 UUID 不得在本机已有（包括远端下载或墓碑），除非有匹配的本地编辑回执。
5. 任务绑定系列、应用首日期/时刻、插入规则、dirty 和编辑回执同事务完成，不创建第二条任务。

新建任务本身仍由原 Todo 新增入口负责，本接口为已保存的普通任务附加规则；后续 UI 必须明确两步保存边界，不能宣称新任务与规则已经一次原子提交。

## 修改周期

- 只接受当前仍活动规则的完整 replaces 快照；本机规则已经推进、被修改或停止时拒绝旧编辑，要求重新读取并确认。
- 必须提供新的规则 UUID，禁止原地修改 schedule、timezone_id 或 first_todo_uuid。
- 一次事务内：旧规则写墓碑，当前未完成任务成为新规则首项，新规则从序号 1 开始。新最大次数从该首项重新计数。
- 已完成历史任务和历史规则内容保留；不批量改写历史，不批量生成未来项，不替用户完成当前任务。
- 修改首项时先释放旧活动关联，再写新规则，避免唯一索引冲突。
- 尚未实现把已停止/耗尽规则重新启用、快捷重复转换、自定义重复转普通任务；这些不得用清空墓碑或清空系列字段代替。
- 两台离线设备同时编辑同一当前任务可能产生两个新规则；沿用既有协议的关联冲突拦截，不静默选择或承诺自动解决。真实双端冲突和后续冲突交互仍为 UI 门槛。

## 日期、提醒与重试

- 全天以 due_date 字面日期为跨端真值；桌面 due_at=null，鸿蒙保留既有 UI 的本地 18:00 投影。
- 定时规则使用既有固定 IANA 时区适配器转换实际 epoch；未知时区或不合法时间整笔拒绝，不回退为设备时区。
- 保存规则会应用该规则的首日期/时间，并清除当前任务旧 reminder_at 和旧 repeat_next_due_date。后续 UI 必须明确展示新日期及“原提醒将清除”，并支持重新设置提醒，不能默默丢失提醒。
- 保存不改标题、备注、分组、置顶、排序或完成状态。
- 修改时间为请求时钟、任务时钟加一、旧规则时钟加一的最大值；超过安全整数范围整笔失败。
- 本地 app_metadata 的 recurrence.edit.v1:<新规则UUID> 保存规范化请求回执，与所有写入原子提交。
- 完全相同请求重放返回该规则的最新状态，不重写日期、规则进度或提醒；规则已停止也不复活。回执存在但规则缺失时拒绝重建。
- 没有本地回执的远端同 UUID 视为冲突，不能凭相似字段认定已执行。后续备份方案必须明确回执恢复/失效策略。

## 停止规则

- stop 使用规则完整快照进行并发核对；规则已推进时拒绝旧请求。
- 只写规则墓碑，保留全部已有任务、任务日期和当前任务提醒；与“删除整个系列”不同。
- 重复停止已停止规则不写入；停止不支持撤销重启。
- 校验、规则写入、dirty 或提交失败均回滚，不留下半条规则。

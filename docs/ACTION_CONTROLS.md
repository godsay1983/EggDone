## 语义与尺寸

| 语义 | 规则 |
| --- | --- |
| 普通/返回/取消 | 固定普通背景、文字和边框，不能依赖系统默认蓝色或灰色 |
| 主操作 | 蛋黄色背景、深色文字，只用于保存/完成等明确主操作 |
| 危险操作 | 危险背景与高对比文字，同时保留删除/丢弃文字，不仅依赖颜色 |
| 禁用 | 独立的禁用颜色；保留原有禁用条件，不能点击 |
| 加载 | 桌面提交按钮使用已有保存状态的aria-busy及进度光标/虚线边框；鸿蒙任务保存时显示本地化“处理中”并禁用 |
| 键盘 | 桌面focus-visible可见轮廓；鼠标悬停不改变语义配色；鸿蒙保留原生Button焦点与状态效果 |

- 桌面：默认12px文字、32px最小高/宽；触屏指针44px最小目标。普通圆角8px，保留桌面紧凑密度。
- 鸿蒙：普通14fp、44vp最小高/宽，Capsule胶囊；任务编辑保存/取消保持原来的16fp、48vp最小高度。文字不设置单行截断，随内容增高。
- 两端保留各自原生字体，不强制跨平台相同字体；主题变化由CSS变量和鸿蒙颜色资源驱动。
- 桌面操作区允许换行，取消部分固定高度；修复全局深色footer样式覆盖共用按钮文字颜色。
- 鸿蒙便签展开操作允许换行；卡片改为最小高度而非固定高度，避免文字增大后把操作挤出卡片。沿用原列数和断点，不引入窗口监听。
- 便签编辑的返回/完成仍调用原来的保存收尾逻辑，不因样式迁移增加“取消保存”或绕过保存失败处理。

## 颜色与验证边界

双端颜色对照保存在 `docs/fixtures/action-controls-v1.json`。普通、主操作和危险颜色复用现有便签/主题资源，增加独立禁用颜色。
八组亮暗/语义颜色的文字对比度计算均不低于4.5:1；桌面浏览器也核对了最终计算颜色，而不是只检查颜色表。
该结果不等于完整无障碍认证，也不代表已测量鸿蒙系统按压、禁用效果及所有实际背景。

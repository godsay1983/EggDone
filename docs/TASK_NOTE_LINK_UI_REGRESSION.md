# 关联界面异常与缩放验证（L4d1）

更新：2026-09-12。基线：桌面659c5b8、鸿蒙675c35f。自动化及有限模拟器检查完成；L4d整体未完成。

## 发现与修复

- 桌面150%缩放、320x430窗口中，关联查看层的返回按钮和关联确认按钮可能超出视口。关联查看/管理/创建弹窗改用包含块百分比高度约束，不再将未缩放的dvh直接用于缩放后的弹窗。
- 关联便签的正文保留最小编辑高度；内容过长可滚动到附件和底部操作，不通过压缩正文至不可操作高度解决拥挤。
- 桌面通用footer规则覆盖便签色块背景和边框。编辑器局部样式恢复五种可见色块，不改全局按钮规范。
- 鸿蒙系统返回原先不知道NoteEditor内部的预览、附件管理和添加菜单状态。现在由当前编辑器登记返回处理器，先关闭内部最上层，再返回关联来源；旧实例销毁不能清除新实例的处理器，设置等外部导航页不被后台编辑器拦截。
- 双端关闭图片预览或离开编辑器时使加载请求失效；迟到的图片结果不能重新打开预览或覆盖较新的图片。桌面清理过时Blob URL。
- 桌面删除便签不再提前取消尚未保存的修改；双端保存失败均阻止删除。删除失败保留当前便签，成功仍走既有删除/墓碑流程。

本轮不改schema、同步协议、版本号、权限或小艺能力，不删除用户便签与任务。

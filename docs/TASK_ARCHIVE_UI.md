## 操作入口

桌面、鸿蒙手机：任务视图“更多 → 已归档”；宽平板：左侧“已归档”，与回收站相邻。
支持标题/备注搜索、分页和只读详情；点击任务后选择操作，再确认才写入。

- 取消归档：保留完成状态、完成历史、清单勾选和有效关联。
- 重新打开：恢复为单次未完成任务，不恢复旧提醒或重复规则；清单勾选不重置。
- 移入回收站：不是彻底删除；解除关联但不删除关联便签。
- 保存后“查看任务”临时显示已完成任务；不主动保存“显示已完成”偏好。鸿蒙同时打开该任务详情。

活动重复规则的当前实例拒绝上述操作，需先处理规则。内容或同步空间变化后须返回列表重新读取详情，不能盲目覆盖。
数据库 schema、同步 JSON、备份 v5、应用版本不变；不修改小艺意图、实况窗或用户真实数据。

## 实现与失败处理

桌面 Tauri archive_commands 获取可信设备身份与时间，API/Store 传递固定请求；鸿蒙 ArchiveStore 的本地端口负责仓库与设备身份。
组件不直接访问数据库或网络。打开前保存便签草稿，处理期间阻止其他搜索/回收站面板和快捷捕获穿透。
详情打开时重新预览；确认前只生成请求，取消零写入。重复点击被拦截，结果不明时复用同一操作 ID 和原快照。
提交成功后刷新任务、便签与关联，并衔接现有同步、提醒/卡片刷新；刷新失败只重试刷新，不再次写入。
失败不冒充空列表；冲突、空间变化和活动规则冲突单独提示，保留搜索上下文。

# 关联内容打开与返回（L4c2）

更新：2026-09-12。双端开发与自动化完成，未发布。L4c1基线：桌面0651dcb、鸿蒙85849cc。

## 操作与边界

1. 任务“更多 → 关联便签”中点击已有链接的“打开”，进入便签编辑器。
2. 便签展开“关联任务”，点击“打开”，进入任务查看层。桌面复用任务行编辑能力，鸿蒙复用现有任务详情，不另造一套任务表单。
3. 便签“返回/完成”、任务“返回来源”逐层返回；支持任务 → 便签 → 任务的嵌套查看。桌面Escape、鸿蒙系统返回优先关闭最上层面板。
4. 打开及返回先等待便签保存。保存或读取失败不切换来源；桌面任务子编辑尚未保存/取消时禁止返回并提示。连续点击不会重复入栈。
5. 不修改主任务视图、分组、搜索或固定筛选。桌面恢复便签正文滚动，鸿蒙恢复编辑器外层滚动；鸿蒙TextArea内部长正文滚动及键盘组合仍待L4d实机检查。
6. 打开前重新读取链接和端点状态；删除/缺失入口不可用，归档显示明确说明并保留链接，不自动取消归档或复活数据。

查看层采用当前窗口内的有界布局，宽度上限960，不按物理分辨率写死手机/平板类型。鸿蒙创建关联任务等面板位于查看层之上。协议、schema、版本、附件本体及小艺能力没有改动。

# 工作回顾与日程创建待办：候选更新说明

日期：2026-10-02。当前候选版本为桌面 1.6.0、鸿蒙 1.7.0 / 1000037；按用户指令升版、生成交接并本地提交。不是已发布公告，未生成新的 Windows/Linux 正式安装包或上传应用市场。

## 工作回顾

从“更多 → 工作回顾”查看指定日期范围内的任务进展，按分组与关键词筛选。可打开原记录，也可复制完整匹配摘要，不限于当前列表页。

已完成和归档任务仍可回顾，回收站和永久删除任务不显示。记录编辑后仍归属于原创建日期。摘要过长会明确提示，不截断正文。

## 从日程创建待办

展开系统日程详情，点击“创建待办”，确认标题、备注和分组后保存；保存成功可“查看任务”。取消不会创建任务。

新任务是独立副本，不回写系统日历，原日程改期、删除或停止共享不改变它。默认不设置截止日期、提醒、重复或今日计划；需要时通过普通任务编辑设置。

同一草稿保存失败后重试不会重复创建。从同一日程重新打开表单，可以明确创建另一条跟进任务。

鸿蒙读取本机日历后即可创建，不要求先开启日历共享。创建后的任务按普通任务同步设置同步；桌面读取共享日程的既有条件不变。

## 兼容性

没有新增权限、同步空间选择或手动迁移。当前数据库 schema 27、便携备份内层 v9、进展与日历共享格式 v1 保持不变。

支持的旧备份可导入；旧版应用可能无法导入 v9，请先升级再恢复。升级前建议保留现有备份。此版本补齐鸿蒙简体中文等待/归档文案，不改变业务行为。

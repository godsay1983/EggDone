# 自定义重复规则传输契约

日期：2026-09-05
阶段：DNS5-D1 / HNS5-D1
状态：独立条件读写和传输回归已完成；尚未接入普通同步流程或规则创建 UI。

## 入口与边界

桌面端：recurrence_transport::RecurrenceTransport，构造时复用现有 rust-s3 Bucket。
鸿蒙端：S3SyncClient.downloadRecurrenceRemote / uploadRecurrenceDocument，复用现有 SigV4 签名和 NetworkKit 请求。

两端从 Todo Object Key 推导同目录 recurrence-rules.json，沿用 B 阶段路径/碰撞校验。
桌面调用方必须传入已配置的便签和附件索引键；鸿蒙使用现有配置的派生键。
目录中的百分号按字面值编码，不做 URL 解码；中文目录及 %2F 已纳入回归。

这些接口只处理一次 GET 或 PUT，不读写本地数据库、不推进任务、不清除 dirty、不修改同步成功状态。
现有手动/自动同步不会调用它们，旧 Todo、便签、附件与实况窗行为不变。
本轮不启用新请求、不新增权限、不修改 schema、版本号或签名。

## 响应与条件写入

| 情况 | 处理 |
| --- | --- |
| GET 200 | 校验唯一有效 ETag、大小、UTF-8 和规则文档后返回 |
| GET 404 | 对象不存在；不把错误响应正文作为规则文档 |
| GET 204 / 206 / 304 | 拒绝，不能当成完整规则文档 |
| 401 / 403 / 限流 / 服务端错误 | 报错；绝不回落为空文档 |
| 损坏 JSON / 错误版本 / 错误领域 / 非法 UTF-8 / BOM | 拒绝；不允许覆盖远端 |
| PUT 200 / 201 / 204 | 只有响应包含有效 ETag 才返回 uploaded 和新 ETag |
| PUT 409 / 412 | 返回 conflict；不在传输层自动重试 |
| PUT 202 | 拒绝，异步受理不能等同于写入已确认 |
| PUT 超时或成功响应缺少 ETag | 结果未确认，向上报错，不 ACK、不自行覆盖重试 |

ETag 是原样保留的非空双引号 ASCII 强标签，长度不超过 1024 字节。
拒绝弱标签、通配符、未加引号、多个 ETag、控制字符和末尾换行。
首次写入仅使用 If-None-Match: *；更新仅使用本次下载取得的 If-Match。
条件头参与现有签名，不存在无条件上传分支。

上传参数必须包含同一传输客户端取得的下载结果，不能直接传数据库缓存的 ETag。
桌面传输客户端持有独立 Bucket 配置快照和身份；鸿蒙同时核对客户端身份和目标配置。
换客户端、换桶、换目录或配置后，旧下载结果不能用于上传。
PUT 返回的新 ETag只供上层确认已写入版本，不能作为自动重试的替代 GET。

## 大小、时限与错误内容

- 原有文档限制继续有效：最多 2000 条规则、输入最多 1048576 个 UTF-16 code unit。
- 本轮增加 3 MiB UTF-8 传输上限；上传先校验并规范序列化。
- Rust 用现有 SDK 签名、分块读取 GET 响应；同时检查 Content-Length 和累计字节数。无长度的 chunked 响应也不能越界累积。
- Rust 规则客户端使用 25 秒请求超时；不改变其他同步领域的客户端配置。
- 鸿蒙请求使用 maxLimit=3 MiB、connectTimeout=10 秒、readTimeout=15 秒、usingCache=false，始终销毁 HttpRequest。
- 鸿蒙解析使用 fatal UTF-8 解码；主机适配验证不能代替设备解码与网络超时验收。
- 网络异常使用固定规则领域错误码；不附带响应正文、签名请求或凭据。损坏 JSON 也不显示解析器截取的原文。
- 尚未将错误码绑定用户可见文案；接入正式同步时必须补齐中英文提示，不能将开发错误码直接展示给用户。

## D2 的接入门槛

1. 修复鸿蒙全天日期的导出/下载物理映射、实例关联与跨时区重投影；本地手动改日期不能被旧回执覆盖。
2. 编排 Todo 下载合并、规则下载合并、确定性补算、Todo 条件上传、规则条件上传，再按各自版本确认。
3. 规则中的当前 Todo 必须已成功上传；Todo 上传失败不得继续上传推进后的规则。
4. 412 或 409 必须重跑完整下载/合并流程，总尝试最多 3 次；不能仅循环当前 PUT。
5. 覆盖配置切换、上传中编辑、部分成功、断网重启、过期确认、关联缺失等场景；只有所有启用领域均确认才显示全部同步成功。
6. 接通普通完成/删除/提醒入口、规则备份恢复及中英文错误提示后，再开放自定义重复 UI。
7. 保留真实 S3 双端同时完成、旧客户端互操作及鸿蒙原生网络/RDB 验收，不能用本地 HTTP 或主机 SQLite 替代。

D1 不代表 NS5-D 整体完成，也不代表自定义重复已可供用户使用。

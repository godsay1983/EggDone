## 用户入口

- 桌面：任务输入框右侧的清单图标（提示“新建任务与清单”）；已有输入及已显示的快捷解析预览、分组带入草稿。
- 鸿蒙手机/平板：新增任务的“选项 → 新建任务与清单”；带入原输入和已选择的日期、提醒、分组、优先级、重复预设，不额外解析标题里的时间。
- 新建面板直接显示标题和备注；任务设置可展开，子项沿用紧凑清单、添加聚焦、更多内排序/删除。
- 未保存子项初始未完成，新建面板不允许提前勾选；已有任务的编辑勾选行为不变。
- 清单可以为空；存在空白子项则必须填写或删除，不能静默丢弃。新增最多 20 项，每项最多 200 UTF-16 单元。
- 保存前取消不写库；关闭面板保留原新增输入框和已选设置，面板内的未保存改动丢弃。成功后清空原新增输入及设置并刷新列表。
- 普通快速“添加”仍沿用旧流程，本阶段仅为“新建任务与清单”入口提供完整原子创建。

## 事务与重试

复用完整任务编辑事务，而不是先调用普通新增、再保存清单。
同一事务写入父任务、任务字段、当前清单、可选重复规则及后续清单定义、领域修改状态和创建回执。
任何校验、清单、定义或回执写入失败都会回滚父任务。没有新增数据库迁移、同步对象、系统权限或依赖。

新建快照只存在内存，父 UUID 在本次面板会话内稳定；不读取一个尚不存在的任务。
保存会话沿用稳定 operation_uuid 与完整负载；回执使用 checklist.create.v1 命名空间，与旧编辑分开。
相同请求重试返回原结果，不因提醒已过期而再次创建。复用操作标识但改变负载会拒绝。
同一父 UUID 已存在（包括已删除）时拒绝新的创建请求，不覆盖或恢复旧任务。
若响应丢失后更改草稿，可能收到冲突；关闭面板检查已创建任务，再从已有任务编辑，不能强制覆盖。

时间、分组、身份、内容和数量在本地仓库/Rust 重新校验，前端通过不是写入授权。
全天与定时日期维持规范表示；新提醒必须在未来。没有清单、日期和备注的普通新任务也写入有效创建/修改时钟。
未修改的其他任务与重复规则不要求全局快照相等，不被本次新建覆盖。

## 重复与系统效果

- 选择每天、每周、每月、工作日或自定义时，创建独立规则及与当前清单内容/顺序相同的后续定义。
- 后续新实例继承清单内容和顺序，子项全为未完成；后端拒绝新建时提交与当前清单不一致的定义。
- 自定义子面板确认仍只更新草稿，最终保存才落库；停止/替换既有规则不属于新建请求。
- 鸿蒙成功提交后刷新任务、卡片与同步状态，再注册新任务的有效提醒；桌面继续使用已有提醒扫描。
- 事务内不调用网络、系统通知或卡片 API，提交后的刷新失败不会重新创建任务。

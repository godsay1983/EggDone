```powershell
node node_modules/@tauri-apps/cli/tauri.js build --debug --no-bundle --config '{"identifier":"com.eggdone.l4d2test"}'
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9228'
$testProcess = Start-Process ./src-tauri/target/debug/eggdone.exe -WindowStyle Hidden -PassThru
node scripts/test-link-native-webview.mjs
```

测试数据只在 `%APPDATA%/com.eggdone.l4d2test` 中，保留QA记录供复核；脚本每次生成新标题，失败也写report.json。它不会安装客户端，拒绝对正式应用标识继续测试。此构建覆盖本地debug exe的应用标识，不是发布包，正常使用应重新按默认配置构建。

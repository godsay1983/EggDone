# 双端模板同步与备份

日期：2026-09-15。P2b-2 已实现，未发布。
上一阶段已提交：桌面 `866c93f`、鸿蒙 `d6a3368`；本阶段改动尚未提交。
应用版本仍为桌面 1.1.0 / 鸿蒙 1.2.0，数据库为 SQLite 21 / RDB 22。

## 同步

- 模板使用 Todo 对象同目录下的 `task-templates.json`，内部 format_version 为 1。校验路径和保留对象冲突。
- 复用有界签名传输：4 MiB、严格 UTF-8/协议、有效强 ETag；错误不输出远端正文或签名信息。
- 只有本次 GET 得到的对象或明确 404 才能生成条件 PUT；HEAD 变化 token 和缓存 ETag 不授权写入。
- 使用 If-Match / If-None-Match，409/412 从整个同步会话重新下载并合并，最多两次尝试；拒绝重复提交旧负载。
- 沿用全会话互斥。合并与快照在短事务内，网络请求不持有数据库事务；模板不依赖原任务存在。
- 独立 revision / synced_revision / generation / etag。上传前及确认时比较完整规范文档、revision、generation 和配置 epoch。
- 上传途中编辑、恢复备份或切换配置，旧快照不能确认新状态；切换配置递增世代、标脏并清除 ETag。
- 无远端对象且本机完全为空才允许无 PUT 确认；墓碑不是空文档。删除仍遵循永久墓碑优先，不自动清理。
- 加入同步待处理汇总及模板独立远端轮询；只消费成功上传/空对象确认 token，不把 HEAD 当同步成功。

共享传输保留既有 ChecklistTransport 类名和 CHECKLIST 传输错误码；wire 分发增加 templates，但模板存储与 ACK 不复用清单 domain。

## 备份 v5

- 普通 JSON 和完整备份的 data.json 均升级 format_version=5，必须带非 null 的 task_templates 文档。
- 完整备份外层 manifest 仍为版本 1，完整性校验及附件处理不变；不导出配置、ETag、同步世代或本机操作回执。
- v5 仍要求有效 recurrence、task_note_links 和两份清单文档；未知字段及非法模板在写入前拒绝。
- 导入 v1-v4 不带模板字段时，保留本机模板及其回执；不允许低版本夹带模板。
- 恢复 v5 与任务、便签、关联、清单处于同一事务。模板合并失败或 ACK 状态写入失败，整笔回滚。
- 恢复不复活墓碑、不清空本地未包含的模板；清除旧模板操作回执，递增世代并标记待同步。
- 预览显示模板记录数及已删除数；旧文件明确说明本机模板保留。
- 旧版应用不能导入 v5，请保留升级前备份。旧端不认识模板同步文件，不应修改该文件；真实旧端混用仍须发布前验收。

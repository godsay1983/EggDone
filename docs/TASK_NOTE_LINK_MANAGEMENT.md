# 关联已有内容与确认解绑（L4c1）

更新：2026-09-12。开发与自动化完成，未升版、未发布。L4b已提交：桌面c566394、鸿蒙e297b00。

## 操作入口

1. 任务的“更多 → 关联便签”：查看关联便签，搜索已有便签并选择，确认后建立关联。鸿蒙任务详情也提供入口。
2. 已保存便签的“添加 → 管理关联”：查看关联任务，搜索已有任务并选择，确认后建立关联。
3. 已关联项点击“解除关联”，再次确认后解绑；取消不会更改关联。解绑不删除任务、便签正文或附件。
4. 操作完成留在来源界面。未保存的便签需先保存，来源保存失败时禁止写入关联。

候选任务包括未完成和已完成任务，不包含已归档或已删除任务。候选便签不包含已删除项。已有链接显示端点状态，正常便签显示“可用”，而不是任务的“未完成”。重复任务只关联当前实例，不向未来实例传播。

## 实现与保护

- 双端LinkManagerStore复用L2原子操作和L3同步协议，不新增数据库字段、备份版本或小艺接口。
- 选择时读取并保留关联预期版本；解绑使用列表对应版本。确认时不重新读取版本后覆盖写入。
- 冲突或失败不会自动重复提交，需重新选择并确认。读取失败显示错误与重试，不伪装为空列表。
- 来源保存先于关联写入；忙碌时禁用确认与关闭，防止重复提交。保存成功与后续刷新失败分别提示。
- 任务侧达到20条关联时禁止新增；本地原子内核继续执行限额及实体有效性校验，两端统一，不依赖应用服务端。
- 桌面使用现有操作按钮和原生dialog；鸿蒙使用ActionButton与有界滚动弹层，保持既有手机/平板页面断点。鸿蒙弹层请求键盘RESIZE避让，退出恢复原模式。

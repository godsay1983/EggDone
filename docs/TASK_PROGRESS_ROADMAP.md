## TP-1：双端功能闭环

目标：完成从记录输入到另一设备展示，以及后续修改、备份和清理。内部按下面顺序实施，保持界面可验证。

### A. 本地数据与界面先接通

- [ ] 双端 migration、repository、模型、写入幂等和预期版本校验。
- [ ] 新增、分页查询、数量聚合、编辑与删除记录。
- [ ] 两端任务菜单和进展面板；先做到保存后立即可见，再接入完整同步。
- [ ] 全部、今天、四象限、日历、等待、搜索、关联详情、归档和回收站入口逐一核对。
- [ ] 空白输入、保存失败保留输入、关闭未保存确认、只读状态、键盘避让。
- [ ] 完成/重新打开保留；归档/回收站只读；复制/模板/重复任务不继承。
- [ ] 主列表计数无逐项查询，面板长文本、分页及菜单不裁切。

A 完成仅记为“本地交互已实现”，作为开发预览，不作为功能发布或跨端验收结论。

### B. 同步、备份和永久删除一起补齐

- [ ] 独立同步对象、ETag 条件读写、首次缺失与曾存在后消失的区分。
- [ ] 接入自动同步、远端检查、dirty、revision/ACK、重试和最终页面刷新。
- [ ] 并发新增取并集，同条编辑确定性合并；编辑对删除不复活。
- [ ] 保存期间父任务归档/删除、同步期间新写入、父任务后到均有测试。
- [ ] 目标切换/自动加入流程处理新域，不能残留旧目标 ACK 或漏迁记录。
- [ ] v9 JSON 与完整备份包含记录；旧版缺域保留本地；新文档严格校验、原子导入。
- [ ] 更新所有现有域的备份版本门禁，完成包含任务、便签、检查清单、模板、今日计划和等待状态的混合备份回归。
- [ ] 接入父任务永久删除的快照、正文清理、终态过滤及远端确认。
- [ ] 旧客户端写入不擦除新域；旧版发起永久删除后新版补清理。
- [ ] 映射领域错误到用户可理解的文案，不将所有失败显示为数据库错误。
- [ ] 同条离线编辑的覆盖提示、未提交输入保留、容量超限保护。
- [ ] 更新 README 功能说明与数据安全说明，不提前改版本号。

出口：双端构建与自动化通过，UI 和数据完整接通，具备进入隔离环境验收的安装包。任何备份遗漏、误报同步成功或永久删除复活问题都阻止该里程碑关闭。

## TP-2：验收与发布准备

### 核心验收场景

| 编号 | 操作 | 应有结果 |
| --- | --- | --- |
| A01 | 新建任务，添加/编辑/删除记录，重启应用 | 状态持久化，计数和列表一致，无重复记录 |
| A02 | 桌面新增后鸿蒙同步，再反向操作 | 内容和时间一致，用户无需配置新路径 |
| A03 | 两端离线给同一任务各新增一条 | 恢复同步后两条都在 |
| A04 | 两端离线编辑同一条；再测试一端编辑一端删除 | 按协议收敛，覆盖有提示，删除不复活 |
| A05 | 请求已提交但返回丢失，重试保存 | 只新增一条；同操作不同正文被拒绝 |
| A06 | 完成、重新打开、归档、取消归档、删除、恢复 | 记录按方案保留，读写权限正确 |
| A07 | 复制、模板创建、重复任务下一实例 | 新任务不继承历史记录 |
| A08 | 永久删除后旧设备上传、旧备份合并导入 | 已知永久删除终态始终阻止任务和记录复活 |
| A09 | 导出 v9 到另一端，导入旧 v8、损坏文档 | v9 内容完整；旧域不擦除；损坏输入回滚 |
| A10 | 断网、错误凭据、冲突、超限、目标切换 | 本地数据保留，状态真实，无跨目标串数据 |
| A11 | 桌面窄窗、各任务视图；手机/平板、键盘、大字体、主题 | 内容可读、按钮可点、浮层不裁切，更新立即可见 |
| A12 | 大量记录下加载、滚动、无变化同步 | 分页稳定，无逐项查询；记录耗时和请求数，无无意义空对象写入 |

- [ ] 执行双端单元测试、协议向量、迁移/备份/同步集成测试及生产构建。
- [ ] 在授权的模拟器完成鸿蒙布局和交互检查；桌面进行实际界面验收。
- [ ] 在隔离测试目标完成 A02-A10，不用用户的真实任务作为破坏性测试数据。
- [ ] 至少一台真机完成输入、重启和跨端同步；手机/平板、大字体与主题记录实际覆盖范围。
- [ ] 测量同网络、同数据下无变化同步与新增记录同步的耗时；区分网络耗时和新增域开销。
- [ ] 形成 TASK_PROGRESS_ACCEPTANCE.md，记录构建、设备、用例、结果、已知限制及证据路径。
- [ ] 用户确认验收后，再按明确指令提升版本、生成 handoff、提交或打包；不自动推送或发布。

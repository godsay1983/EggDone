# 自定义重复编辑界面与验收契约

日期：2026-09-06
阶段：DNS5-E3C / HNS5-E3C
状态：双端候选版 UI 已接通；原生设备和真实 S3 验收待完成，不代表正式发布验收。

## 入口与操作

- 桌面：已保存任务的日期按钮，或“更多 → 设置日期”，进入“自定义重复”；已有规则可点任务下方摘要打开。
- 鸿蒙：任务“更多 → 编辑 → 时间 / 提醒 / 重复的设置 → 自定义重复”；已有规则可点任务下方摘要打开。手机和平板共用编辑器。
- 新任务先由原入口保存，再附加规则。当前日期面板或任务编辑尚有修改时，先保存修改，不静默丢弃草稿。
- 保留每天、每周、每月、工作日四个快捷选项。旧快捷重复须先选择“不重复”并保存，才可另建自定义规则。
- 历史项、已停止/耗尽规则及未知关联仅展示摘要和限制说明；需另建普通任务，不能通过清空墓碑重启。
- 仅活动规则的当前未完成任务可改规则或停止。停止需要确认，保留任务、日期、提醒和历史。

## 表单与语义

- 每 1–99 天/周/月；周可多选星期；月可选 1–31 日或月末，短月取当月最后一天。
- 首项日期为所选起点当天或之后第一个匹配日期，保存前显示实际首项日期。
- 全天使用字面日期；定时使用 HH:mm 和固定 IANA 时区。时区无效时整笔拒绝，不猜测设备时区。
- 可永不结束、截止日期（含当天）或 1–100000 次（含首项）。
- 保存应用首项日期/时刻，清除旧提醒，界面明确提示；用户可回到日期设置重新配置提醒。
- 当前任务完成只生成下一项，不按时钟自动生成，也不批量补建漏过实例。
- 改周期创建新规则并停止旧规则；当前任务成为新系列首项，次数重新计数，历史保持不变。
- 规则摘要显示周期、星期/月内日、时刻/时区、结束条件、停止/结束状态；桌面长文本省略并提供 tooltip，鸿蒙两行省略后可点开完整摘要。

## 数据与旧入口保护

- UI → store → API/Repository；不在 ArkUI 组件或 Index 中操作数据库、网络。
- 保存带任务 updated_at 和旧规则完整快照。过期编辑显示重新打开提示，不覆盖其他设备。
- 相同草稿失败重试保留 UUID、时钟和请求，复用已落库回执；不通过重复点击新建多个规则。
- 普通日期修改保留自定义系列字段，不能用旧快捷选择器覆盖规则；清空已完成/归档不停止活动下一项。
- 保存/停止后刷新列表和规则摘要、安排自动同步。鸿蒙重新协调提醒与桌面卡片；桌面未来提醒由既有数据库轮询读取新状态，已展示的系统通知仍受平台生命周期管理。
- 不增加数据库 schema，不改同步规则 v1、版本、签名、权限或已验收实况窗。

## 布局

- 桌面原生 dialog，固定头尾、可滚动表单，最大宽度 480px；320px 窄窗口不横向溢出。
- 鸿蒙组件级尺寸适配（SIZE-00/SIZE-04）：遮罩内独立编辑层，最大宽度 540vp，正文滚动，头尾固定；星期及底部动作允许换行，按钮采用原有胶囊与亮暗主题色。不改主页面导航结构。
- 设备大字体、输入法避让与平板横屏仍须原生检查，不能用浏览器截图替代。

## 自动化证据

- 共享 recurrence-editor-form.json：25 个有效/无效、月末、闰年、星期、结束、时间用例；TS/ArkTS 使用相同纯函数和样例。
- 桌面新增 28 个前端测试及 3 个 Rust 旧入口回归。
- 鸿蒙 test-recurrence-ui.cjs：31 场景，使用生产 ArkTS 和 SQLite 宿主适配器，覆盖表单保存推进、旧入口、并发拒绝和摘要。
- 桌面 check-recurrence-ui.cjs：真实 Svelte 组件、隔离的 Tauri transport；17 个浏览器场景涵盖 320/480/920px、中英文亮暗、失败重试请求一致、只读历史、停止确认及日期草稿保护。模拟 transport 不等于原生 IPC。
- 构建与最终套件结果以两端 Roadmap 的 E3C 记录为准。Mate 80 Pro Max 模拟器已覆盖安装启动，原生入口、规则读取、按周下拉及取消草稿 smoke 通过；未向已有任务写入测试规则，这不替代原生保存/同步验收。

## 本机门槛

| 状态 | 处理 |
| --- | --- |
| 正在同步 | 拒绝并发检查，保留原锁所有者 |
| 目标 epoch 缺失、空或 pending | 阻止使用当前预览 |
| 没有成功同步记录，或最近结果为失败/离线/冲突/中断 | 阻止使用当前预览 |
| 任务/分组、便签、附件元数据 dirty | 逐域列出待同步项 |
| 重复规则、关联、清单条目/定义、模板 revision 不等于 ACK | 阻止使用当前预览 |
| 非删除附件 remote_uploaded=0 | 文件待上传，不受界面缓存计数影响 |
| 文件已上传，但 transfer_state 仍为 uploaded 等中间态 | 元数据未完成同步，继续阻止 |
| 删除附件从未上传 | 单列待处理，不静默丢弃或自动上传已删除内容 |
| 状态行缺失、未知/损坏 dirty JSON、非法数字 | 失败关闭，不能降级成“没有待同步内容” |

兼容现有规则同步：仅当 rules 表完全为空且 ETag 为 null 时，允许该领域因切换目标而产生的无 ACK 修订。两端现有同步都会跳过空规则领域；只要存在任一规则（包括停止记录），或已有 ETag，就仍要求 ACK。修订号仍保留在快照中，变化会使旧确认失效。此例外不证明远端规则已校验，远端阶段必须独立读取/验证。

## 备份盘点与缺口

盘点包含 9 类业务记录（任务、分组、便签、附件、规则、关联、清单条目/定义、模板），额外列出归档任务、删除任务/便签、重复实例保护记录、本机便签历史与清单/模板操作回执数量。数量只用于预览，不替代领域解析、引用完整性或内容摘要。

original_paths_missing / preview_paths_missing 只表示数据库缺少路径，覆盖删除记录。它不是文件存在、可读、长度或哈希校验；有路径也可能缺文件。云端已有但本机未下载的附件不算待上传，仍需要下载并验证才能纳入完整本地备份。

已核对现有真实备份代码，未修改格式或导出行为：

| 现有能力 | 当前边界 |
| --- | --- |
| v5 业务导出 | 包含业务文档与重复实例保护信息，不等于整个应用数据库备份 |
| 普通 JSON | 不是含二进制的完整备份，附件集合构造与 full 模式不同 |
| 完整备份包 | 对未删除附件逐个验证原文件/图片预览，写 manifest；已删除附件二进制被跳过 |
| 本地历史、幂等回执、偏好、凭据、提醒登记等 | 不能宣称都包含在 v5 包中；本轮不导出敏感配置 |
| host 迁移 Journal 的原始云对象备份 | 不包含全部本地状态，不能代替以上备份 |

因此本机 blockers 为空不提供 migrateReady/backupVerified 这样的承诺。下一阶段须绑定实际备份产物及摘要，明确已删除附件、本机历史和保护记录的保留策略，验证落盘、重开读取、文件缺失、磁盘错误及中断恢复；不能用勾选框或仅有数量代替备份证明。

# 系统日历共享与展示

日期：2026-09-20。CAL-2 开发增量；未升版、未发布。真实日历和用户云端验收按要求后置。

## 操作

1. 鸿蒙进入“日历”或“设置”，找到“系统日程”，点击“读取系统日历”并授权。
2. 勾选需要展示的日历，点击应用，确认本机日程读取成功。
3. 点击系统日程旁的齿轮，开启“共享到其他设备”开关，阅读上传内容说明并确认。
4. 桌面沿用同一套同步配置。打开日历后可见“系统日历”；前台普通任务同步结束后独立更新，也可点日程区刷新。
5. 系统日历发生变更后，回到鸿蒙或手动刷新读取；桌面随后获取新快照。桌面不能唤醒手机读取日历。

已有同步配置无需填写新的 Object Key，也无需迁移同步空间。应用仅读取系统日历，不创建提醒、不编辑日历，不将日程计入任务或今日计划。

桌面默认只显示日程、只读标记和工具栏；点击标题右侧“日历同步详情”信息图标，可查看来源设备、采集/接收时间、时区、覆盖范围及缓存说明，再次点击收起。刷新失败、来源快照超过 24 小时和日期覆盖不完整等提示不受折叠影响。详情只查看本地状态，不触发额外同步。

2026-09-20 精简验证：`pnpm check` 无错误/警告，`pnpm build`、`pnpm i18n:check` 通过；前端 518 项测试通过。Playwright 中英文、明暗、320/480/1000 宽度共 12 组通过，覆盖默认无元信息占位、键盘展开/收起、不触发额外 IPC、配置切换隐藏旧详情和异常提示保留。使用合成数据，截图已检查；当前桌面原生外观仍请用户确认。

## 来源与隐私

- 首次共享上传所选日历显示名、日程标题、起止时间、时区及地点。不上传备注、参会人、会议链接、账号邮箱或坐标。
- 数据存储于用户配置的 S3/MinIO。具备该位置访问权限的设备可以读取共享内容。
- 一套同步配置只接受一个主动发布来源。其他鸿蒙默认接收；本机也启用读取时，可选择本机或共享来源，二者不叠加。
- 更换采集设备时，在新设备读取成功后点“改用此设备提供日程”并确认。旧设备不得自动抢回来源。
- “停止共享”先记录本机停止意图，再撤回远端。断网时显示待同步；已离线的接收设备需联网更新后才能清除旧副本。
- 调整选择或关闭本机读取时先停止共享，避免继续上传取消选择的日程。读取成功后可重新确认开启。
- 远端使用不含日程正文的撤回记录，不删除整个同步位置。对象存储版本历史和外部备份不由应用清除。
- 改同步配置前建议先停止共享并同步。若仍继续更改，会提示旧位置可能保留副本；新位置需要单独同意共享，不能沿用旧授权。
- 日程缓存与任务库隔离；鸿蒙发布身份和待撤回状态从系统备份中排除，不修改任务数据库版本和任务导出格式。

## 状态

任务同步和日历同步独立。任务成功不会因日历权限不足、网络失败或格式不兼容被改成失败。日历区单独显示错误和重试。

日程按照当前查看设备的时区显示，全天日程保持原日期。跨时区的范围边界标为可能不完整，不把未覆盖日期当作没有日程。成功下载时间与手机实际采集时间分别显示；重新下载旧快照不代表手机刚刚读取过日历。

同步配置改变会隐藏旧配置的缓存。在原位置缺失、被其他设备接管或已经撤回时，不会自动使用旧缓存重新上传。

## 验证边界

自动化只使用合成日程、临时目录和本机 HTTP 服务，不访问用户实际云端或系统日历。构建与自动化结果另列于 roadmap；以下仍须发布前验收：

- 新 Profile、只读权限授权/拒绝/撤销，系统日历实际账户可见范围。
- 真实普通、重复、单次修改/取消、全天和跨时区日程。
- 鸿蒙手机/平板的主题、语言、大字体与原生布局。
- 实际 S3/MinIO 上的共享、刷新、接管、关闭、断网重试和配置切换。
- Windows/Linux 原生客户端展示、真实托盘显隐和系统备份恢复。

范围内尚未通过的真实测试不能用 mock、浏览器截图或编译成功替代。

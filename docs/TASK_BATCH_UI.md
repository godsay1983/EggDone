# 批量创建界面（P3b）

日期：2026-09-15。桌面 1.1.0、鸿蒙 1.2.0，schema 及同步格式不变。
P3a 已提交：桌面 `c9589db`、鸿蒙 `fd77e88`；本阶段新界面按用户授权本地提交，未发布。

## 操作入口

- 桌面：首页“更多 → 批量创建任务”，位于任务模板之后、搜索任务之前。
- 鸿蒙：新增任务“选项 → 批量创建任务”，位于模板入口之后。
- 输入或粘贴多行文本，点击“预览”，逐行修改、勾选并选定统一分组，最后点击“创建 N 项”。

预览保留原行号，重复标题显示提示但不自动去重。空白、超长、非法标题在行下提示；取消选择无效行后可创建其余有效项。修改后重新计算重复状态，返回再预览未改变的原文时保留行内修改和勾选。

每批最多 50 个非空行、原文 20000 UTF-16 单元；不截断超限文本。条目默认未完成、无日期/提醒/重复，不解释自然语言时间。不存在的分组必须重新选择。

## 提交与失败行为

两端使用同一提交会话规则，调用 P3a 原子接口，不从界面逐条创建：
- 预览、勾选、改字、关闭未提交草稿均不写入任务。
- 提交中禁用编辑和重复确认；成功后进入完成态，不能再次创建同一批。
- 结果不确定时锁定原负载，保留 operation UUID 及全部任务 UUID，点击“原样重试”不会重新分配身份。
- 明确的提交前分组校验失败可重新编辑；旧回执失效提示先核对任务列表，不自动创建替代批次。
- 创建成功和列表刷新分开处理；刷新失败只显示“刷新列表”，不再次调用创建接口。
- 在当前主页面实例存活期间，关闭并再次打开保留未完成会话；已经完成的会话下次打开为新批次。
- 暂未持久化输入草稿与未确认请求。进程退出后需先核对已有任务，不应盲目重新创建；跨进程恢复及完整错误收尾属于 P3c。

鸿蒙粘贴通过 `PasteButton` 授权成功回调后读取系统剪贴板；桌面只在用户点击粘贴时调用浏览器 Clipboard API。都不在打开面板时读取。粘贴追加到原文末尾；失败保留原文，可使用输入框原生粘贴菜单。

## 布局

复用现有主题、动作按钮和单列表单，未增加主导航。手机/窄窗口保持单列；宽屏居中限宽，不放大字体和按钮。原行号/勾选固定在左，输入区占剩余宽度，工具按钮不足时换行。滚动仅作用于内容，确认操作保持可见。

鸿蒙容器最大宽度 560vp、目标高度 620vp，上限为可用高度的 90%，键盘模式使用 RESIZE，退出恢复原模式。标题 18fp、正文 16fp、辅助文字 14fp，各尺寸保持 1x，不新增窗口监听。桌面最大宽 520px，实际尺寸受当前窗口约束，字号 13px，标题 15px。

- P0 18 组草稿回归与双端文档/代码一致性验证通过；P3a 的 42 场景 repository 回归保留。

浏览器使用隔离创建/刷新适配器，不读用户数据库；宿主面板测试不等于 ArkUI 真机渲染。未安装或操作手机/平板，原生剪贴板授权、真实键盘、分屏/大字体、实际 S3 与恢复链路尚待 P3c/P3d。既有模板人工验收仍待确认。

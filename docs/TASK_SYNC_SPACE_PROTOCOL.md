## 本轮范围

双端生产传输层支持独立新空间的八类元数据封装，同时保留原空间格式。
本轮没有新界面，也没有开放空间切换。普通同步入口明确拒绝新空间配置，返回 SYNC_SPACE_ACTIVATION_REQUIRED；
必须等原子激活证明与终态感知同步一并接齐后再解除。不能仅凭传输已通过就让用户修改 Object Key 绕过迁移。
真实 S3 测试直接调用生产传输层，初始化只发生在测试创建的隔离桶，不是用户迁移向导。

## 候选格式

新空间元数据键限定为 `eggdone-spaces/v2/<canonical lowercase UUID>/<file>`。
固定文件及域为：

| 文件 | 域 |
| --- | --- |
| todos.json | todos（含分组） |
| notes.json | notes |
| note-attachments.json | attachments |
| recurrence-rules.json | rules |
| task-note-links.json | links |
| task-checklist-items.json | items |
| task-checklist-definitions.json | definitions |
| task-templates.json | templates |

封装字段仅四个：
```json
{"format_version":2,"space_uuid":"00000000-0000-4000-8000-000000000001","domain":"rules","payload":"{\"format_version\":1,\"rules\":[]}"}
```
payload 是保留内部文档的 JSON 字符串，避免更改已有领域合并规则。
解封后仍调用原生产领域校验器；内部格式必须为 1，外部格式必须为 2，拒绝未知字段、错误空间/域、嵌套封装或未来版本。
外部格式 2 不能被旧版八域解析器当成合法的格式 1 文档；隔离测试已验证其拒绝行为。
这不是访问控制或加密，持有 S3 写入凭据的外部工具仍能破坏对象。

暂存区 `eggdone-migration-staging/v1/...` 与此运行空间不同，禁止将暂存 manifest 当作运行空间或激活证明。
新空间八个对象都必须在正式激活前初始化；没有内容的域也需要合法空文档，不能依赖第一次正常同步创建。

## 安全行为

- 原空间键走原格式，保留原缺失对象及旧版兼容流程；保留原字节编码与生产合并规则。
- 新空间 GET 404 报不完整，不返回空远端；新空间 HEAD 的 404/403 等不会进入旧版可选域降级。
- 新空间正常上传必须持有已有对象 ETag，使用 If-Match；不得从“无远端”分支执行 If-None-Match 创建。
- 新空间下载、解封和上传签名覆盖的是封装后的实际字节，ETag 对应远端完整封装；冲突仍由原同步协调器处理，不退化为无条件覆盖。
- 桌面任务/便签/附件元数据的新空间下载使用有界流式读取，强 ETag、HTTP 200 与严格 UTF-8 检查。鸿蒙检查相同状态与强 ETag，沿用 NetworkKit 响应上限。
- 封装后规则最多 3 MiB，关联/清单/模板最多 4 MiB，任务/便签/附件元数据最多 5 MiB；超限拒绝，不截断。JSON 字符串转义会占额外空间，正式迁移预检还需提前检查实际封装大小。
- 普通服务的新空间保护在凭据读取/网络同步前生效；直接填写新路径不会触发同步。已有终态阻断和旧空间禁止永久删除的条件保留。
- 应用尚未发布该能力；新增终态域和激活契约可继续调整。未来不能把本轮“只会八域封装”的构建视为已支持永久删除的新端。

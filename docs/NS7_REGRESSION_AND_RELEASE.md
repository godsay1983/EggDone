## 变化摘要

- 同步：持久化同步状态和待同步域，配置切换隔离旧回包，独立重复规则对象参与同步和前台变更探测。
- 智能列表：逾期、未来 7 天、无日期、重要、最近完成，支持已有分组/搜索组合，本机记忆。
- 快速收集：桌面快捷键/命令行，鸿蒙系统文字分享入口；确认后才保存任务或便签。
- 通知完成：按平台能力提供动作，复用幂等事务；不承诺所有平台都有同样的后台动作。
- 自定义重复：日/周/月间隔、星期、多种结束条件、全天/固定 IANA 时区、只读历史、编辑和停止。
- 规则备份：数据格式 v2 包含规则及可移植实例回执，保留停止状态和更新进度。
- 原生回归修复：鸿蒙时区列表缺少 UTC 别名时使用固定零偏移；未知时区仍报错，不静默降级。
- 测试可靠性：冻结 v14 数据库样本、按语言导航的 UI 冒烟、主包先于测试包覆盖安装、严格 Hypium 报告检查；桌面上传超时测试不再误限前置下载。

## 安全复跑

鸿蒙从仓库根目录执行：

```powershell
.\scripts\check-i18n-release.ps1
.\scripts\run-device-tests.ps1 -Device '<实际设备ID>'
node scripts/test-device-test-report.cjs
```

设备脚本要求本机已配置 devecocli、Node 和调试签名；构建串行、主包先装、只覆盖安装、失败立即停止，不卸载重试。当前自带 `onDeviceTest` 会先卸载应用，**不要用于有数据的设备**。测试使用独立临时库；建议专用测试设备，仍应先备份重要数据。

桌面运行 `pnpm release:check`；浏览器脚本为 `scripts/check-recurrence-ui.cjs`，需在本地 Vite 上运行，并用 `PLAYWRIGHT_PATH` 指向本机 Playwright。不能把 mock 的成功当成系统动作成功。

## 用户可操作的重点路径

1. 已保存任务 → 更多 → 编辑/日期提醒 → 自定义重复。创建“每 2 天，累计 3 次”的全天规则，核对首次日期、摘要和清除旧提醒提示。
2. 完成当前项，确认只产生一个下一项；另一端同步后再完成/取消完成，检查没有重复生成或进度倒退。
3. 编辑周期、停止、删除本次/整个系列，确认已完成历史保留且停止状态不会因同步复活。
4. 在隔离环境导出 v2 JSON 和完整附件备份，另一端恢复，检查规则数、任务、原图和文件，再同步。
5. 同步诊断、智能列表、文字快速收集和系统入口依各契约执行，异常时保留诊断与时间，不记录访问密钥。

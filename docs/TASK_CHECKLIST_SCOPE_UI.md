## 入口与行为

- 两端已有任务的清单面板改用完整编辑快照和原子保存接口。
- 可编辑的自定义重复任务显示“清单应用范围”：默认“仅本次”，也可选“本次及以后”。
- 仅本次：只修改当前标题、备注和清单，不改系列定义。
- 本次及以后：当前清单与新系列定义一起保存；停止旧规则、创建新规则，但保留历史任务和历史定义。
- 后续任务继承内容与顺序，子项默认未完成；当前任务已经勾选的项目保持勾选。
- 切换范围本身不保存，取消不写库。失败保留草稿和选择；相同负载重试保留操作、规则和定义子项身份。
- 清空全部子项并保存到以后，写入明确的空定义，不把“没有定义”误当作清空。
- 新规则从当前实例重新计数，限制按“原总次数 - 已生成次数 + 1”计算。例如第 3/5 次只保留当前与后续共 3 次。
- 下一次是否存在由两端已有重复引擎在快照事务内计算，不在 UI 另写日历算法；日期截止早于下一次时禁用以后。
- 日期、提醒、分组、优先级没有编辑控件，原值原样保留。全天日期不变成定时；过去的原提醒不重新注册。
- 标题变更后仍走现有提交后提醒刷新；范围修改不重排当前提醒。未来提醒延续原有重复行为，不新增提醒规则。

## 边界

- 普通重复（daily/weekly/monthly/weekdays 旧式字段）暂仅支持当前清单，不在这个面板内自动转换重复类型。
- 已完成、已停止、历史实例、无下一次、无法确认系列身份的任务，不提供可用的以后选项。
- 当前日期与自定义规则不匹配时不暗中修改日期；全天在范围判断中禁用，定时由生产事务校验并显示日期不匹配错误。
- 未来定义最多 20 项。已有导入清单超过 20 项仍可编辑当前内容，但不能直接转为以后定义。
- 本轮不是整个 P1d-2b：完整日期/提醒/分组/优先级/重复配置尚未合入清单草稿，仍在后续阶段。
- 新建任务时添加清单（P1d-2c）、已保存详情即时勾选（P1d-2d）、普通重复转换和真机/S3 验收尚未完成。

## 布局

沿用上一轮紧凑面板，不扩大正文或主按钮。范围选择是两项单选，选中状态明确。
桌面选项自动换行；鸿蒙使用 FlexWrap，手机/平板共用业务逻辑和控件，不新增窗口监听或断点。
范围与说明位于可滚动主体内，保存/取消仍在主体外；键盘避让和新增子项焦点保持现有方案。

## 人工验收

1. 打开有后续次数的自定义重复任务清单，确认默认仅本次。
2. 修改子项，选择本次及以后，取消，重新打开确认原内容和规则未变。
3. 再次修改并保存，确认当前进度、日期和提醒；完成当前任务，检查下次清单内容与顺序，默认未勾选。
4. 次数限制任务核对没有重新从原总次数开始；历史任务内容保持原样。
5. 手机/平板小窗、键盘展开、英文、大字号下，范围选择和保存均可达。

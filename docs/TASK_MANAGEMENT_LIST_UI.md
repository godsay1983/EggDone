# 归档与回收站列表优化

日期：2026-09-17。本轮为双端展示和布局优化，按用户要求纳入本地提交，未发布；原生视觉验收范围未另行确认。

## 调整范围

- 两端统一轻量列表行：标题、状态/类型与日期、可选单行备注。去除整条记录的大块按钮背景和空备注占位；标题最多两行，元信息允许换行，完整内容在详情查看。
- 桌面归档复选框置于左侧独立列，与标题对齐；实际复选框支持键盘，点击文字区也可切换选择，互不重复触发。
- 鸿蒙归档和回收站复用 ManagementListRow；选中状态整行有浅色底，未选中使用透明底和细分隔线。
- 搜索图标与输入框同排，键盘搜索保留。批量入口位于标题栏，刷新和关闭使用图标并提供可访问名称。
- 选择模式标题栏显示已选数量和取消；全选明确仅针对已加载记录，提供部分选择状态和清除选择入口。分页新加载的记录不自动勾选。
- 批量模式底部仅保留移入回收站和取消归档；普通列表不再为刷新、关闭保留底栏。搜索/选择工具位于列表滚动区之外。
- 当年日期省略年份，跨年保留年份；详情仍显示完整日期时间，不依赖悬停查看。
- 沿用品牌亮暗主题与现有字号，不按平板尺寸放大控件。鸿蒙图标按钮最小 44vp，正文 16fp、辅助文字 14fp；桌面正文 14px、辅助文字 12px。

## 边界

- 未改数据库、Store 写入、同步协议、分页查询、批量目标快照、操作回执、恢复与失败重试逻辑。
- 未增加全库选择、清空回收站或新批量操作。
- 桌面使用同一份局部 management-dialog.css；鸿蒙仅归档/回收站使用新列表行和工具按钮，不调整全局 ActionButton。
- 保留鸿蒙有明确高度的面板及中间 Scroll，最大宽 600vp、高 680vp，并受窗口 90% 高度限制；窄屏/大字体允许工具和详情操作换行。批量底部两项操作等宽，按钮文字允许换行，避免按钮纵向堆叠挤掉列表。

## 验证

- 桌面 Vitest：48 个文件、409 项通过；svelte-check：0 错误、0 警告。
- 桌面归档/回收站各 24 组中文/英文、亮/暗主题、窄/宽窗口、100%/150% 缩放 UI 测试通过；浏览器截图已检查。
- 归档额外 8 组窄/宽窗口、中文/英文及 100%/150% 缩放批量布局与恢复通过；覆盖复选框左对齐、鼠标/键盘单次切换、部分选择、搜索栏固定、分页选择、底栏不越界和中断恢复。
- 鸿蒙归档单条/批量面板、回收站 Store host 测试通过；Debug HAP 构建通过，原有 SDK 警告仍存在。
- UI 自动化使用实际桌面组件和隔离 IPC，不访问用户数据库或 S3；鸿蒙 host 测试不等同原生渲染或真机验收。
- 本轮未安装或覆盖用户设备应用，手机/平板及原生桌面仍需视觉验收。

## 验收步骤

1. 双端打开已归档，检查顶部搜索、批量选择、刷新和关闭；滚动列表时工具栏保持可见。
2. 进入批量选择，分别点复选框和任务文字，确认一次只切换一次；加载更多后新增记录不应自动选中。
3. 检查取消位于标题栏，底部只有两项业务操作；取消不修改数据，执行仍先确认。
4. 打开回收站，检查紧凑列表、空备注无占位、详情完整日期与恢复流程。
5. 手机竖屏、平板横竖屏/分屏、英文和大字体检查标题换行、按钮可达及键盘弹出时的可操作性。

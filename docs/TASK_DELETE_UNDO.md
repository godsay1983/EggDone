# E5b 鸿蒙任务短时撤销

日期：2026-09-11。前置E5a由用户确认真机验收通过，本阶段独立验收。

最新确认：用户本轮确认E5b测试通过，授权两端提交并开始E5c。下文“待验收/未提交”是开发阶段记录；未逐项给出机型、提醒及异常网络用例，不扩大为完整专项矩阵通过。不推送、升版或发布。

## 范围与入口

- 鸿蒙任务更多 → 删除，确认删除当前项或整个重复系列后，底部显示6秒撤销条。
- 批量删除共用同一入口；只保留最近一次删除操作。新任务/便签删除替换旧提示，不叠加两种撤销条。
- 点击撤销后按钮进入忙碌态，阻止重复执行；超时或页面销毁丢弃临时回执，不额外删除数据。进入后台后即使定时器延迟，点击时也校验实际截止时间。
- 部分恢复失败时只保留失败及尚未尝试的回执，显示6秒重试入口；已恢复或已变化的项不重复恢复。
- 桌面沿用已有撤销入口。本阶段不改桌面业务代码、不新增完整回收站，也不承诺重启后保留撤销。

## 数据与并发保护

- TodoRepository在数据库事务提交后返回实际删除记录的快照。自定义重复跳过当前项时，记录重复引擎在同一事务中生成的墓碑。
- 批量操作每个成功事务独立回传；后续失败不能丢掉此前成功项的撤销机会。全部回滚不提供撤销。
- 恢复在共享重复操作队列和数据库事务中核对UUID、deletedAt、updatedAt、updatedBy，且任务未归档。远端新修改、新删除或已恢复时跳过，不能覆盖新状态。
- 仅清除任务删除标记并单调递增更新时间；保留内容、分组、日期、提醒、完成状态。无新数据库字段或同步协议。
- 删除当前自定义重复任务视为跳过，撤销不回退规则进度或删除已生成的下一项。整个系列删除后恢复现存任务，但规则保持停止；恢复任务不等于恢复系列运行。
- 删除后取消旧提醒；恢复后复用现有提醒/卡片协调器，重新安排未来未完成任务的提醒，已完成任务不重新提醒。已过期提醒不补响。
- 删除及恢复实际成功后标记待同步并沿用自动同步；部分成功也不能因页面错误状态漏掉同步调度。不绕过S3冲突、ETag或会话保护。

## 实现位置

- 鸿蒙：`TodoRepository.ets`提供已提交回执及受保护恢复；`TodoStore.ets`编排部分结果与提醒刷新。
- 鸿蒙：`TaskUndoBar.ets`复用ActionButton及既有主题；`Index.ets`只管理最新回执、定时器、页面状态和操作入口。
- 平板原有任务统计Builder使用值参数，删除/恢复后可能保留旧数字；改为`TaskStatCard.ets`显式响应式属性，侧栏与详情概览复用，不改变统计口径或卡片样式。
- 中英文文案齐全，底部条按容器宽度约束，不使用固定高度；手机和平板共用逻辑。

## 用户验收步骤

1. 创建一条测试任务，设置未来提醒。删除后6秒内点“撤销”：任务及日期/提醒恢复，标题没有丢失。
2. 再删除并等待超过6秒：提示消失，任务不自动恢复。连续删除两条时只能撤销最近一次。
3. 新建两个测试任务，批量删除并撤销：恢复被删除的两项，不影响其他任务。
4. 用测试用的自定义重复任务删除当前项并撤销：旧项恢复，下一项不重复生成；删除整个系列并撤销：已有任务恢复，但规则仍停止。
5. 鸿蒙删除测试任务后手动同步，再撤销并同步，桌面应恢复同一UUID的任务，而不是新增副本。6秒内操作不便时先单独验证本地，再在恢复后同步两端。
6. 在手机和平板检查底部提示、英文/大字体下文字和按钮是否完整，提醒到点是否按已有系统授权状态正常触发。

只操作专门创建的测试任务；不为测试清空数据或修改用户已有重复系列。E5b用户验收已确认，后续按授权进入E5c；回收站及任务便签关联不在本阶段。

# 双端任务快捷复制

日期：2026-09-15。阶段：P2a，开发分支未发布。
上一轮清单收尾回归已提交：桌面 e85574b、鸿蒙 7931922；未推送。

## 入口与行为

两端任务“更多 → 复制任务”，普通任务和有清单的任务均可使用。
读取原任务最新已保存内容，打开现有“新建任务与清单”草稿；保存前不创建任务，取消不落库。
复制保留标题、备注、有效分组、未删除清单项的文字和顺序；全部子项重置为未勾选。
失效分组降级为未分组；超过本地 20 项清单上限明确提示，不能静默截断。

复制不继承原任务或子项 UUID、完成/归档/删除/置顶状态、重要程度、日期、提醒、重复规则、
清单系列定义、便签关联、附件及专注记录。草稿中可重新设置任务字段。
不自动解释复制标题中的自然语言日期。复制快照生成后，原任务与新草稿相互独立。
鸿蒙复制不会清空首页尚未提交的快捷输入；读取期间返回或退出页面后，迟到结果不再打开面板。

## 实现边界

- 两端 TaskCopyDraft 复用 P0 copyTaskForCreation 和已有输入校验；只从白名单字段构造新草稿。
- store 读取完整编辑快照并核对父 UUID；任务行的旧标题和未保存编辑内容不能冒充已保存快照。
- initialItems 只预填界面，创建会话的 expected_items 仍为空，expected_updated_at 为 0。
- 确认调用已有原子创建命令，父任务、清单和操作回执一起提交；失败整笔回滚。
- 不确定结果的重试沿用相同请求和操作身份；不会重复创建，也不会写回原任务。
- 不修改数据库版本、同步对象、备份格式、小艺、实况窗或应用版本。
- 任务模板管理和多行批量创建尚未实现，不能用快捷复制替代 P2/P3 的完成。

## 简单验收

1. 找到一个含已勾选子项、日期和提醒的任务，打开“更多 → 复制任务”。
2. 核对标题/备注/清单文字已填好，子项均未勾选，日期、提醒、重复已清空；取消后任务数不增加。
3. 再复制一次并修改标题后保存：只新增一项，原任务保持不变；同步后另一端显示新任务及未勾选清单。

# 检查清单 UI：P1d-1

日期：2026-09-14。状态：开发分支已实现，未发布；不代表完整 P1d/P1e 已完成。

## 本轮入口与范围

- 桌面、鸿蒙手机和平板：已有任务的“更多 → 检查清单”。
- 支持修改标题、备注，新增/编辑/勾选/删除/排序当前清单；保存一次原子落库，取消不保存任何草稿改动。
- 任务行显示非空清单的“已完成/总数”；两端均可点击计数直接打开面板。没有子项时仍从“更多 → 检查清单”添加。
- 新增最多 20 项；同步导入超过 20 项时全部显示，仍可编辑、勾选、删除，只禁止新增。
- 全部子项勾选不自动完成主任务。完成主任务不清空清单；归档只读；删除父任务隐藏清单，恢复后重新显示。
- 当前面板不更改日期、提醒或重复规则，也不修改系列定义。当前实例的临时清单不会自动继承给以后实例。
- 标题/备注和清单共用本轮快照及事务，不与另一个尚未保存的任务编辑面板混用。

## 实现

桌面：TaskChecklistDialog → taskChecklistStore/taskChecklistApi → task_checklist_commands → task_checklist_views/task_checklist_store。
鸿蒙：TaskChecklistPanel → TaskChecklistStore → TaskChecklistViewRepository/TaskChecklistRepository；Index 仅负责入口、刷新和提醒编排。

读取标题、备注、父任务版本和子项（含墓碑）使用同一只读事务。保存校验父版本及完整子项快照，拒绝旧草稿覆盖新状态。
操作 UUID 在失败重试时保留；负载修改后生成新 UUID。保存期间禁止重复提交、取消和系统返回关闭。
保存失败保留草稿；冲突提示取消后重新打开，不自动覆盖或丢弃当前输入。
提交成功后再刷新列表、进度与同步状态；鸿蒙标题改变时刷新尚未触发的提醒。刷新失败不能变成再次保存的邀请。
进度按整批任务刷新查询，不为每一行单独查询。读取失败隐藏计数，不虚构 0/N。
本轮不修改数据库版本、同步格式、软件版本、小艺或实况窗。

## 布局

桌面面板最大宽度 440，鸿蒙最大宽度 560；主体独立滚动，保存/取消在滚动区域外。
桌面密度与主任务列表对齐：任务标题/子项 13px，面板标题 15px，按钮文案 12px、鼠标操作高度 32px；触摸设备保留 44px 点击区域。不额外改变 zoom，全局缩放同时作用于主页面和清单。
鸿蒙使用现有覆盖面板与键盘 RESIZE 避让，按清单数量和展开状态计算高度，最多 640vp 且不超过可用高度的 90%；短清单不再占据整屏。
默认展示任务标题，点击“编辑”再展开标题/备注输入。子项以“勾选 + 自动换行正文 + 更多”排成一行，排序/删除仅在该项展开时显示。
桌面正文按实际行数和可用宽度伸展，不显示固定大文本框或拖拽手柄；展开管理操作允许换行，不压缩输入宽度。
鸿蒙任务行的计数使用小型按钮，点击后不同时打开任务详情；任务更多中的“检查清单”和“关联便签”并排，沿用同组字号和高度。
手机/平板共享业务逻辑，不新增断点和窗口监听；组件级约束覆盖小屏/大字体/分屏，真实设备布局仍待验收。
桌面按钮沿用 action-button，鸿蒙沿用 ActionButton；支持亮暗主题和中英文。

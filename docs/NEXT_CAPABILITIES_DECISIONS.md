# NS6 后续能力决策

日期：2026-09-06
适用：桌面与鸿蒙。此文完成原 Roadmap 的设计决策任务，不表示下面功能已经编码或发布。

## 依据和排序

用户已反复验收便签、图片/文件、跨端同步和任务入口，现有两端 Todo 与 Note 都有稳定 UUID；尚无“子项强制完成”或跨设备专注统计的明确需求。当前优先完成 NS1–NS5 的发布验证，下一功能候选选择 **任务与便签关联**，以连接已有信息与行动，不新增主导航。
这是基于现有反馈作出的工程决策，不伪造新的用户调研结论。

| 能力 | 决策 | 不做项 |
|---|---|---|
| 任务与便签关联 | 选为下一独立功能，先冻结 link 协议和分阶段方案 | 不自动复制附件、不级联删内容、不批量继承到重复任务 |
| 轻量检查清单 | 暂不进入本轮编码；保留每任务最多 20 项的单层草案 | 不做子任务树、依赖、主任务强制门槛 |
| 专注历史 | 首版只做本地统计，待单独排期 | 不同步正在运行的计时、不做排行榜、不改实况窗状态机 |
| 端到端加密 | 仅完成威胁模型，安全原型与独立评审前不编码正式功能 | 不把 S3 凭据当加密密钥，不宣称已有同步为端到端加密 |

任务关联配套 [实现方案](TASK_NOTE_LINK_IMPLEMENTATION_PLAN.md) 和 [Roadmap](TASK_NOTE_LINK_ROADMAP.md)。本轮 NS6 不把候选 Roadmap 递归扩成已经承诺的发布范围；NS7 验收完成后再启动该功能实现。

## 专注历史边界

桌面 FocusWindow 当前维护计时和阶段切换；鸿蒙 FocusSessionRepository 的 Preferences 保存活动会话快照，用于恢复与实况窗，不是完整历史数据库。不能把活动快照当历史累加器。
后续独立方案须定义：
- 按 session UUID + phase 序号唯一记录完成的专注段；自然完成只计一次，休息不计入。
- 记录实际专注毫秒数，排除暂停；跳过/提前结束是否计部分时间先在独立契约中冻结，不由客户端各自猜测。
- 默认今日/近 7 天摘要，按记录的本地日归属；不随设备时区变化改写既有记录。
- 独立本地表，不写 Todo/Note 或其同步对象；统计失败不可中断计时、通知、实况窗。
- 后续若要求跨设备统计，先另设事件对象、去重、删除和备份规则，不同步活动计时控制权。
上述是设计约束，尚未接入统计写入。

## 检查清单边界

当前不增加任务行按钮。候选是任务详情内单层、最多 20 项，独立 item UUID、task UUID、内容、排序、勾选和墓碑。主任务默认可独立完成；重复任务是否复制检查清单需要单独决定。没有用户反馈证明应强制依赖，故不实施强制完成。
未来若启动，先提交独立实现方案、同步/并发策略和 Roadmap，不能将整个数组塞入 Todo 单条记录。

## 无服务端加密威胁模型

安全设计应包含密钥生成、存储、轮换及恢复流程，并使用成熟认证加密能力；不自行设计密码算法。参考 [OWASP Cryptographic Storage](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html) 与 [Key Management](https://cheatsheetseries.owasp.org/cheatsheets/Key_Management_Cheat_Sheet.html)（2026-09-06 核对）。下面是本项目的候选边界，不是已验证实现。

| 威胁/故障 | 必要设计 | 残余风险 |
|---|---|---|
| 存储桶泄露、服务商读取 | 客户端加密全部业务 JSON、原图、预览和备份；文件名、标题不进入对象名/明文元数据 | 大小、访问时间及对象数量仍可能泄露 |
| 错误密钥、对象篡改、截断 | 认证失败整笔拒绝；类型/版本/对象标识绑定到认证数据 | 不自动把损坏对象当空库覆盖 |
| 桶回滚至旧版本 | 本机保存已见世代，检测倒退，保留版本化备份 | 全新设备没有可信最新检查点时，无法完全识别有效旧密文回滚 |
| 设备丢失或凭据库清空 | 用户持有离线恢复包或另一可信设备；导入前验证指纹 | 无服务端托管，全部恢复材料丢失则不能找回 |
| 忘记解锁密码 | 有恢复包时重新包装数据密钥；没有则只允许新建独立保险库 | 不提供后门或假装能重置解密旧数据 |
| 密钥泄露、设备撤销 | 新世代数据密钥、重新加密，确认新快照后切换 manifest；可中断恢复 | 旧设备已下载的明文无法收回 |
| 轮换时设备离线 | 老世代只读，重连需获取新密钥；禁止旧设备继续覆盖新世代 | 未升级客户端不能进入加密目录 |
| 本机恶意程序/已解锁设备 | 系统安全存储、锁定态最小驻留、日志脱敏 | 不能承诺抵抗已经控制终端的攻击者 |
| 误清空、勒索删除 | 加密不替代备份；恢复演练、版本保留 | 未保存备份的数据仍可能丢失 |

密钥层次候选：随机数据密钥与包装密钥分离；系统安全存储仅持有本机解锁材料，恢复包由用户离线保管。密码派生、算法、nonce 策略和文件流式分块协议必须在双端官方 API/成熟库原型、性能测试及安全评审后冻结，本阶段不指定未经验证的参数。
迁移使用新目录和可恢复 manifest，不在原明文对象上边迁移边覆盖；确认完整解密校验、备份和设备升级后才允许用户显式清理旧明文。自动日志不得包含密钥、密码、恢复包或解密正文。

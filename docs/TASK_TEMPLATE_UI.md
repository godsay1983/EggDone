## 入口与操作

1. 两端在任务“更多 → 保存为模板”打开草稿，读取任务最新已保存的标题、备注、分组和有效清单项目。修改模板名称后点击“保存模板”。
2. 桌面：首页“更多 → 任务模板”，位于智能列表分隔线后、搜索任务前。鸿蒙：新增任务“选项 → 任务模板”；任务展开操作区也提供模板入口。
3. 模板列表可以搜索名称、标题、备注和清单文字。点击模板进入预览；“编辑”修改名称和内容，“删除模板”需要再次确认。
4. 点击“使用模板”打开现有新建任务与清单草稿，可继续设置日期、提醒和重复；最后点击“保存”才创建任务。取消不创建任务，也不清空首页原有输入。
5. 同一个模板可多次生成独立任务和清单。模板的编辑、删除不会修改此前创建的任务，删除原任务也不删除模板。

## 数据与失败边界

- 模板只保留名称、标题、备注、分组 UUID、清单文字；不复制原任务/子项 UUID、完成、置顶、重要程度、日期、提醒、重复、附件或关联。
- 使用模板时重置所有子项为未完成，独立分配新任务及子项 UUID；创建的冲突基线为空，沿用原子创建和稳定回执。
- 失效分组显示提示，必须主动选择其他分组或未分组，才可保存/使用。预览中的分组选择用于本次创建，不自动改写模板；修改模板分组需“编辑 → 保存模板”。
- 每行一个清单项目，不自动删除中间空行或截断超限项目。清单最多 20 项用于本地新建与使用；远端超限模板可完整查看，修正后再使用。
- 本地最多 100 个活动模板；已有模板维护、远端超限记录保留及冲突语义沿用 repository。
- 独立编辑会话保留完整 expected 快照；同一请求失败重试复用操作 ID。修改失败后输入仍保留；其他设备修改/删除引起的冲突不会被覆盖，可显式重新加载。
- 关闭、返回列表不自动保存模板。删除需要二次确认且写入同步墓碑，不删除已有任务。
- UI 不直接访问数据库。桌面通过独立 IPC 和 store，鸿蒙通过 store 与组件回调；写入成功后才调度同步，调度错误不伪装成数据库失败。
- 关闭后丢弃迟到的读取结果；写入过程中阻止退出和重复提交。

## 布局

桌面复用 13px 内容、15px 标题、32px 常规按钮，触摸按钮最小 44px。弹层宽度上限 480px，百分比视口约束兼容现有 150% 缩放；内容滚动，操作区换行。

鸿蒙复用 ActionButton、主题资源和现有弹层：最大宽度 560vp、高度 620vp 且不超过容器 90%，内容独立滚动，软键盘采用现有 RESIZE 模式。手机、较小平板和分屏不扩大字体或硬塞一行按钮；实际键盘、横竖屏及大字体仍待设备验收。

# E4 任务行与便签操作

更新：2026-09-11。用户确认E4验收通过；本轮平板返回任务入口补充修复待设备确认。未升版、未发布。

## 实现范围

- 两端任务标题优先，长标题随内容增高；分组、日期、提醒和重复标签不足宽度时换行，不通过缩小字体挤进一行。
- 完成与更多操作位于任务行顶部两侧，不随下方备注/标签数量垂直居中漂移。桌面更多按钮默认可见，不依赖悬停。
- 桌面便签默认仅显示内容、置顶标记及更多入口。置顶/取消置顶、换色和删除在更多中展开；收起同时关闭色板。
- 桌面右键便签正文可展开相同操作，更多按钮仍是主要入口；支持 Enter 展开、Escape 收起并返回更多按钮焦点，点击卡片外收起。
- 鸿蒙复用已有更多/收起与长按入口，正文单独处理打开事件。操作已展开时点击正文仍可进入便签；按钮不通过根节点事件误触发打开。
- 两端便签标题最多两行，正文与附件继续使用摘要。鸿蒙附件辅助文字统一至少12fp，附件摘要用最小高度承接文字；不改变原图下载、排序或保存行为。

不改数据库、同步协议、任务编辑保存/取消规则、重复任务推进、小艺或实况窗；不提前进入E5，也不引入新断点或窗口监听。

## 布局边界

本阶段是组件级自适应，保持现有手机/平板、列表/四象限/日历及便签网格结构。

| 场景 | 保留内容与操作 | 变化 |
| --- | --- | --- |
| 桌面窄窗口/缩放 | 标题、完成、更多、全部元信息 | 标题和标签换行；长标签采用较小圆角 |
| 鸿蒙手机/窄分屏 | 相同任务语义和操作 | 内容占剩余宽度，更多预留空间；不限制标题/重复摘要为单行 |
| 平板宽窗口 | 现有分栏/网格及同一业务逻辑 | 沿用容器宽度，不按屏幕宽度放大字体 |
| 便签多附件 | 第一项预览、数量与文件名摘要 | 仍为摘要而非大图；长文件名可省略，打开便签查看完整内容 |

长任务可以占多行，列表仍负责滚动；备注与便签正文摘要可以省略，不承诺首页显示附件完整文件名。

## 人工验收步骤

1. 两端准备一条长标题任务，设分组、日期、提醒和普通重复，再检查一条已有自定义重复任务。查看全部、今天、四象限和日历：标题/标签可读，完成与更多不会挤出右侧。
2. 桌面缩小窗口并切至150%缩放；鸿蒙在手机、平板横屏/分屏检查相同内容。切换英文和深色，增加系统字号，确认无重叠和无法点击的操作。
3. 打开便签列表：默认看到内容、置顶标记和更多。点击更多后操作完整；换色、置顶不意外打开编辑器，删除保留原有确认流程。
4. 保持便签操作展开，点击正文，应直接打开该便签。桌面再验证右键、键盘 Enter/Escape、收起后色板关闭。
5. 检查无附件、仅文件、多图片混合文件三种便签；摘要不遮挡更多，进入编辑后原有查看、排序与附件操作仍可用。

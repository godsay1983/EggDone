# 自动接续同步位置

日期：2026-09-19。双端实现、HTTPS 历史绑定修复与隔离往返验证完成，纳入本次本地提交；未推送、未升版或发布。不是实际用户设备验收记录。

## 问题与目标

已确认一次真实故障：桌面配置指向已迁移的 v2 位置，鸿蒙仍指向旧位置；两端分别同步成功，但桌面新任务及今日计划无法到达鸿蒙。此前要求用户手动理解并加入同步空间，不符合预期。

正常手动同步、自动同步和前台轮询应发现可信的既有关联，自动完成接入。用户不选择空间，不重做全量备份或创建新空间；完成接入和内容同步之前不得报告成功。

## 安全边界

- 只跟随当前存储目标内已发布的 source association，验证源绑定、目标 ready 标记与协议。没有关联时维持原同步位置，不自行创建迁移。
- 拒绝错误绑定、损坏关联、未就绪目标、权限失败；不得降级为继续向旧位置写入并报成功。
- 保留本机未同步任务、便签、检查清单、模板、今日计划及永久删除记录。目标终态优先于旧正文，避免复活已清空的记录。
- 目标切换与同步世代、激活证明、待同步状态在本机事务内完成；旧 ETag 或旧会话不能确认新目标的数据。
- 附件按引用与内容指纹检查，只补目标缺失的必要文件，不覆盖不同内容，不重新复制目标已有一致文件。云端唯一副本不能因改路径变得不可访问。
- 中断后从可验证进度重试；本地内容仍可用，不自动删除旧空间或备份，不修改用户存储权限。
- 配置页自动刷新内部路径，保留其他未保存的表单修改，防止旧表单将目标改回旧位置。

## 验证要求

1. 无关联、已有 v2、已有可信关联三个正常分支。
2. 旧目标 ETag 不变时，新的关联也能触发同步。
3. 一端已迁移并创建任务/今日计划，另一端从旧配置通过一次正常同步看到内容，同时保留其离线修改。
4. 目标永久删除优先；完成记录、清单、附件、关联和计划不能因接入复活或丢失。
5. 权限不足、网络中断、目标未就绪、错误哈希、配置改变、回复丢失和重试。
6. 接入期间保持同步中，失败不报成功；正常用户界面不再显示迁移/加入按钮。

## 隔离双端测试

桌面 `scripts/run-sync-core-s3.ps1 -AutoJoinSessions -HarmonyRoot D:/Develop/EggDoneHarmony` 使用临时 SeaweedFS、合成凭据和独立数据库，不连接用户桶。覆盖真实 Rust/ArkTS 同步服务及 HTTP；鸿蒙宿主适配不替代原生设备验收。

实际手机、平板及用户云存储验收另行记录。旧版本不具备自动接入能力，参与设备应更新。

## 用户验收

### 存储路径设置

- 首次配置继续使用已有默认任务路径 `eggdone/todos.json`，无需手填随机标识；其余路径由程序派生。
- 既有 `eggdone-spaces/v2/<UUID>/todos.json` 是此前迁移流程生成的路径，保持原值；本轮界面修改不创建空间、不迁移、不重写路径。
- 常规页面显示“存储位置：自动管理”；已有非默认自定义路径如实显示为自定义。Object Key 与派生路径移入默认折叠的高级设置，默认只读，只有显式开启路径编辑后才可修改任务路径。编辑仍需保存，失败保留输入，自动接续位置仍会刷新表单。
- 需要连接已有自定义存储时，高级设置沿用原来的任务路径及账户配置；应用不会猜测任意路径之间的关联。
- 本轮桌面 473 项单测、类型检查、构建和文案检查通过；隔离浏览器 12 组计划/标签回归、24 组导入预览及 12 组设置回归通过，覆盖默认、生成、自定义路径的保存、取消修改、保存失败和自动目标刷新。鸿蒙 6 组标签/路径专项主机测试及既有界面回归通过。无实际账户、凭据或云端操作；主机测试不替代原生显示验收。

### HTTPS 历史绑定兼容修复

2026-09-19 用户验收报告 `SYNC_AUTO_JOIN_BINDING`。旧来源指纹包含 `allowHttp`，导致同一个 HTTPS 目标在两端 HTTP 风险确认开关不同的情况下被当作不同来源。修复仅在 HTTPS 下验证原指纹或反转此单一开关后的旧指纹；Endpoint、Region、Bucket、Object Key、Path Style 仍必须完全匹配。HTTP 不接受该兼容分支。

不改历史指纹算法、不重写云端关联、不变更用户开关或凭据；就绪标记、完整性、固定关联及终态保护均保留。鸿蒙提交事务改用本机捕获的精确配置指纹，防止验证通过后再次被旧来源指纹误挡，也继续拒绝接入期间发生的配置修改。参与设备升级后通过正常同步重试，不需要调整配置。

修复验证：Rust 自动接入 11 组、鸿蒙宿主自动接入 28 场景通过，覆盖开关两个方向、事务激活及真实身份不匹配仍拒绝；鸿蒙 Debug 签名 HAP 构建通过。七阶段隔离 S3 往返再次通过，证据目录为临时目录下 `eggdone-sync-core-c77695ad4a944d3fbbf2aba8f0981a64`，临时服务已移除。未修改实际配置或云端数据，实际设备升级后的重试结果仍待用户确认。

更新双端后使用已保存的同步配置：桌面新增任务并加入今日计划，执行正常同步；鸿蒙执行正常同步，应在“全部”和“今天 → 计划做”看到同一任务。再从鸿蒙新增并安排一项任务，桌面同步后应看到。无需选择空间或重新备份迁移；异常时保留本地修改并显示失败，可通过正常同步重试。

自动接入仅针对同一配置下已有且校验通过的关联；不会猜测两个不同账户、存储桶或任意路径应如何合并。旧位置和旧备份仍保留，旧版应用无法自动跟随，需升级后使用。
